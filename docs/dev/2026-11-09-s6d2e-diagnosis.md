# S6d-2e 진단표

직전 S6d-3c 결과를 `data/derived/items/*.prev-s6d3c.{json,md}`로 보관했다. 네 번째 확인의 문서와 변환 text만 개발 참고로 사용했다. 정답 자료와 세 번째 필드 표본은 읽지 않았다.

| 유형 | 원문·기존 후보에서 확인한 원인 | 일반 규칙과 처리 |
|---|---|---|
| 1. 세부 배점 열 | 오현 중1 2학기 표 53, 중2 2학기 표 157: 과제명 셀 하나가 두 열을 덮고, 위에는 총점 100, 아래에는 방법별 50·50 또는 40·60이 있음. 기존에는 leaf 열의 배점을 항목 만점으로 채택 | 같은 제목 셀의 열을 한 과제로 묶는다. 총점 셀을 score, 방법별 배점을 sub_scores로 보존. 수준별 점수는 합산하지 않음 |
| 1. 성취기준 열 | 상북 중2 2학기 표 57: 제목·100점·30%·시기는 두 열 병합, 성취기준만 두 열로 나뉨 | 하나의 제목 셀 아래 코드 집합을 합친다. 평가유형에 적힌 ‘페임랩 발표 평가’는 영역 관측으로 보존하여 상세표와 비교 |
| 1. 연속 표 | 동일 과제명의 반복 form, 또는 같은 과제 머리글 아래 끊긴 채점표를 별개 항목으로 셀 수 있음 | 같은 표 또는 새 머리글 없는 인접 표에서 문자 그대로 같은 과제명과 필드 근거가 있을 때만 합침. 다른 과제번호·새 머리글은 분리. 제목만 같은 약한 근거는 검토 |
| 2. 조각 제목 | 갈산 중2 2학기 표 29의 수행과제 셀이 ‘혈액의수’, 성취기준도 ‘[9과’로 끊김. 뒤 평문과 표 30에 나머지 설명이 따로 있음 | 최소 길이·조사 말미·‘의수’와 같은 미완 어절 검사. 조각을 제목 근거에서 제외하고 원문 관측은 보존. 떨어진 문장을 임의로 합성하지 않음 |
| 3. 공유 성취기준 | 장흥유치 중2 1학기 표 107. 실제 PDF 133쪽도 성취기준이 네 영역을 가로지르는 병합셀 하나임. 코드별 줄 정렬만으로 항목 귀속 불가 | 항목의 제목 열 경계 안에 온전히 들어오는 PDF 성취기준 rectangle만 해당 항목 소유. 가로지르면 shared로 보존하고 항목별 값은 unconfirmed. 상세표 자체의 기준과 구별 |
| 4. PDF 2학기 | 장흥유치 PDF 40쪽. 중2 표는 표 29(라벨·포트폴리오)와 표 30(숫자·제목·코드)으로 나뉨. ‘2) 2학년’이 표 29 앞에 있어, 표 29 뒤만 찾던 학년 정렬에서 탈락 | 이전 조각표 앞부터 숫자 core까지의 마지막 학년 표지를 확인. 물리 PDF 학년과 원문 학년이 일치해야 복원. 열별 값은 해당 원문 셀·부분 범위에 유일하게 대응할 때만 사용 |
| 5. 영역명과 과제 | 갈산 중2 1학기 용해도는 이미 S6d-3c에서 수행과제 문장으로 bounded 복구됨. 과학 논술은 일반 영역명 목록에 없어 구체 과제와 같은 종류로 경쟁. 2학기 검전기·혈액순환 문장은 PDF 변환에서 평문/조각으로 분리 | ‘과학 논술’도 일반 영역명으로 처리. 온전한 수행과제 셀 > 영역명 순서를 유지하고 영역명은 assessment_area에 보존. 구조가 끊긴 PDF는 기하와 원문 범위가 입증되기 전까지 검토 |

학교명·코드·파일명·해시·좌표에 따른 추출 분기는 추가하지 않았다. 이 문서의 원문 사례는 진단 설명이며 추출 규칙에 들어가지 않는다.
