# S6d-2f 정밀도 진단표

S6d-2e 마지막 확인까지의 다섯 astra 목록과 지정 변환 JSON의 `text`만 개발 참고로 삼았다. 원문 파일은 수정하지 않았다. 보충 80칸을 모두 사용했으므로 독립 표본은 추가하지 않는다.

| 유형 | 원문·기존 후보에서 확인한 원인 | 일반 규칙·예외 |
|---|---|---|
| 1. 요약표 하위 칸 분할 | 대전대화 중2 두 학기: `영역 및 방법` 라벨이 두 행 병합이다. 첫 행의 한 과제명 셀은 두 열 병합, 다음 행에는 실험·실습과 서·논술형 평가, 각 10점·10%가 있다. 기존에는 첫 행을 방법, 다음 행을 영역으로 읽어 3개가 따로 생김. 1학기 text 2221–2229줄, 2학기 2167–2175줄 | 첫 행의 과제명과 다음 방법 행을 구별한다. 동일 제목 셀 아래 하위 열을 합치고 만점·비율·논술비율은 같은 행의 명시적 배점만 합산한다. 인쇄된 총점이 있으면 우선하며 수준별 점수는 합산하지 않는다. 다른 상위 제목 셀은 분리한다. 기존 순서·문자 그대로 제목 및 독립 필드 동일성 규칙으로 상세와 연결한다. |
| 2. 점수 처리 규정 행 | 장흥유치 중1 1학기 확인의 잘못 4개는 수치 채점표 안의 반복 `평가 항목` 머리글과 마지막 기본점수·미제출·특수교육 처리 행이다. 상단 평가영역/값 형태를 무시하고 중간 행을 새 항목표 머리글로 선택함 | 상단 라벨/값 form을 우선한다. `평가 항목`은 채점요소 열로 취급한다. 규정 어휘의 행 머리는 항목으로 읽지 않으며, 처리 기준 열과 다수 대상별 규정 행으로 된 독립 표는 score_policy 검토 자료로 남긴다. 실제 평가표 안의 기본점수 안내 때문에 표 전체를 버리지 않는다. |
| 3. 방법 행 제목 및 일반 성취수준표 | 광양마동 중2 2학기 text 1941–1950줄: `구술·발표포트폴리오관찰평가 기타(문제해결)` 같은 붙은 선택지가 제목으로 승격됨. 한편 2213줄 이후 `단원명 / 교육과정 성취기준 / 평가기준` 일반표도 별도 과제로 추출됨 | 방법 어휘 전체로만 구성된 붙은 문자열·체크 행을 제목에서 제외한다. 평가영역 행의 실제 제목이 남아 상세와 연결된다. 단원·성취기준·평가기준/수준의 같은 머리행은 일반 성취수준표로 분류한다. 단어를 포함하기만 하는 실제 활동 문장은 제외하지 않는다. |
| 4. 단원 나열 제목 | 평동 중2 1학기 text 5157줄에 `수행평가 영역명: 수업밀착형`, 5160줄에는 `지권의변화, 빛과파동, 물질의 구성`이 있음 | 활동 동사가 없는 짧은 쉼표 나열을 제목 근거에서 제외하고 인접한 명시 영역명·과제명을 우선한다. 관찰·기록·분류·분석 같은 활동명 나열은 이 음성 규칙에서 제외한다. |
| 5. 단원 번호 내용 행 | 로마숫자 뒤 점만 제외하던 규칙이 `Ⅱ-2-(5)`·`Ⅲ-1-(3)` 형태를 통과시킴 | 대단원-중단원-소단원 번호로 시작하는 값은 제목 근거로 쓰지 않는다. 별도 명시 과제명·만점·비율이 있으면 그 독립 근거로 항목을 검토할 수 있다. 단원 번호만 남으면 bounded로 확정하지 않는다. |
| 6. 놓침: 영역 안 비율·짧은 영역 | 광양마동 중2 1학기 text 1680·1700줄은 `물질의 특성 반영비율 20%`처럼 한 셀에 영역과 라벨·비율이 함께 있음. 중1 1학기 1685줄의 `열`은 최소 제목 길이에서 탈락하고, 불완전한 상세 form과의 동일성 미확정 때문에 요약도 검토로 이동함 | 구체 영역명 뒤의 완전한 `반영비율 N%` 문법만 원문 부분 범위로 분리한다. 일반 방법/영역명과 비율만 있는 애매한 셀은 기존 검토를 유지한다. 명시 영역명 라벨과 성취기준이 함께 있으면 1~2글자 영역을 허용한다. 대표 제목이 없는 상세 후보는 요약 동일성 경쟁자로 쓰지 않는다. |

학교명·파일명·코드·해시·좌표로 추출을 분기하지 않는다. 원문 코드와 영역의 교육적 적합성은 이 작업에서 확정하지 않는다.
