# S6e-3b 표 기하 판정과 칸 원문 값 읽기

2026-11-09

## 1. 바꾼 점

- 열·행형 소속을 같은 표의 제목류 라벨과 실제 칸 좌표로 증명한다. 첫 자료 열과 다른 자료 열에 같은 규칙을 적용한다.
- 제목 칸 자체의 인용은 제목의 열 소속으로 받는다. 다른 행의 필드 칸은 제목 아래에서 다음 제목 라벨 블록 전까지 받는다.
- 같은 제목이 요약표와 세부표에 반복되면 인용 표 안에서 정규화 동일 제목의 유일한 기하 앵커를 찾는다. 같은 정규화 제목을 가진 중복 항목은 다른 제목으로 세지 않는다.
- 제목 라벨의 값 영역은 같은 행의 다음 필드 라벨 전까지다. 만점·시기 라벨 뒤의 숫자나 월을 다른 과제 제목 후보로 세지 않는다.
- 세부표는 다른 알려진 제목과 제목 라벨의 다중 후보를 배제한다. 바로 다음 한 표만 제목류 라벨과 다른 제목이 없는 경우 연결한다.
- structure_verified 값과 별도로 격자를 재구성하여 빈 좌표, 겹침, 범위 밖 rowspan을 거부한다.
- AI는 인용할 칸을 고른다. 칸 전체 원문에 기존 standard_values, method_values, field_value, numeric_spans, enrich_claims, sub_score_field를 적용한다. 값을 만들지 못한 경우에만 AI 글자 대조를 적용한다.
- 코드 값과 AI 값 차이는 ai_value_mismatch, 값 출처는 value_source에 기록한다. rubric은 인용 위치로 비교한다.
- HTML 줄바꿈 뒤의 요소명 조각을 완전한 요소명으로 저장하지 않도록 단일 행의 완전한 요소(점수) 쌍에만 인라인 규칙을 적용한다. 잘못된 AI 값 형식도 코드 값의 저장을 방해하지 않도록 비교를 보완했다.
- 병합 뒤 재검증은 최초 입력 백업 해시, 규칙 항목 바이트, 식별자 순서, 메타데이터와 직전 검증 결과를 대조한 경우 허용한다. 대상·지시문·저장 응답은 그대로 재사용했다.

## 7. 남은 위험

- 정규화 동일 값 버림 55건이 남았다. 제목이 표 밖에 있거나 제목류 라벨이 없는 다중 과제 표, 제목 행 위의 공통 값, 서로 다른 행, 파싱 경계 불일치, 다른 알려진 제목이 있는 세부표는 요청한 소속 조건으로 증명되지 않는다.
- 같은 값이라는 사실을 소속 증거로 사용하지 않았다. 해당 조건의 확대 없이 잔여 버림을 더 줄이기는 어렵다.
- rubric은 위치만 대조한다. 새 수용 중 규칙 rubric과 위치가 다른 건은 그림자 불일치로 남는다. 규칙 값 자체도 정답으로 확정하지 않았다.
- 변이 시험의 실제 문서는 열형 위주다. 행형·반복 블록·모호한 양축·다음 표 제한은 합성 테스트로 검증했다.
- 코드가 인용한 칸 전체를 읽으므로 AI가 적은 부분 문자열보다 넓은 값이나 배점 설명을 저장할 수 있다. 차이는 ai_value_mismatch 전체 목록에 남겼다.
