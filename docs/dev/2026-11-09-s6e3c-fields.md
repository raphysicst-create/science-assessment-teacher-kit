# S6e-3c AI 필드 값 분리와 소속 판정

2026-11-09

## 1. 바꾼 점

- method는 원문 칸의 `<br>`·줄바꿈으로 원소를 나누고 각각 method_literal을 통과시킨다. 체크박스 선택은 기존 규칙 문법을 재사용한다.
- task_text는 검증된 인용 하나를 원소 하나로 사용한다. 인용 안의 `<br>`·줄바꿈은 공백으로 바꾸고 칸의 인용되지 않은 부분은 넣지 않는다. standards는 기존 개별 코드 추출·범위 확장을 재사용한다.
- 다른 제목 후보는 title이 present이고 candidate_role이 performance인 bounded 규칙 항목과 ai_verified/ai_read 항목이다. 라벨을 제외한 칸 전체와 정규화 일치해야 하며 현재 제목과 같거나 포함 관계면 제외한다.
- own_block은 유일한 제목 칸부터 다음 확정 다른 제목 행 또는 제목류 라벨 행 직전까지다. 인용 칸의 rowspan 전체가 그 범위 안에 있어야 한다. 블록 경계 밖 인용은 own_table로 우회할 수 없다.
- 제목 라벨 옆에 값이 있는 세부 양식은 행형 요약표 머리 행으로 취급하지 않는다. 세부표의 단독 영역 머리 행만으로 다른 블록을 추정하지 않는다.
- 빈 rowspan의 오른쪽 꼬리만 다음 행 끝 칸에 덮이는 경우를 허용한다. 데이터 칸의 시작 열·폭은 그대로이며 내용 있는 중첩, 내부 빈칸, 비직사각 격자는 거부한다.
- 개발 items에서 method는 목록, task_text는 단일 문자열 또는 독립 관찰별 목록인 것을 확인했다. AI 필드의 목록 형식에 맞추되 독립 원소 경계는 유지했다.
