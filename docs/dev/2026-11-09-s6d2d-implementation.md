## 2. 바꾼 파일·일반 규칙

- `scripts/middle_assessment_scope.py`: 문서 전체 평가표 귀속. 과목 칸 또는 과목 머리글을 우선 사용하고, 둘 다 없을 때 혼합되지 않은 `[9과…]` 코드 접두를 과목 근거로 사용한다. 다른 과목 칸·머리글이 있으면 코드가 있어도 채택하지 않는다. 무코드 표는 과목 칸·머리글이 필수다. 학년·학기는 코드 번호로 추정하지 않고 문서 구조·학년/학기 칸·기존 근거로 확인한다. 확정 근거를 `boundary_evidence.assessment_scope`에 남긴다.
- `scripts/middle_pdf_summary.py`: 필드 라벨 없이 숫자·코드만 남은 PDF 요약표를 진단한다. 원문 수행평가 그룹의 물리적 셀 범위에 들어가는 열만 복원한다. 시험 열은 제외한다. 각 값은 변환 원문에서 유일하게 대응하는 셀·부분 범위를 찾아 기록한다. 원문에 없는 값과 모호한 대응은 채우지 않는다. 페이지·bbox·원문 값을 `source_cell_proof`에 기록한다.
- `scripts/middle_items.py`: 전과목·전학년 행 표에서 과목·학년·학기 및 rowspan을 확인해 행 필터를 적용한다. 미정 학년과 빈 과목 칸은 다른 행의 값을 상속하지 않는다. 과제 제목 앞 범위를 확인하고 한국어 꺾쇠 제목을 보존한다. 소유가 확정된 단일 수행과제는 줄바꿈·서술문도 원문 그대로 대표 제목으로 사용한다. 성취수준 문장·번호 목록·조사 단편은 제외한다. 중점 변형을 영역 판정에서도 인식한다. 규칙 버전은 `middle-items-v11`이다.
- `scripts/middle_fields.py`, `scripts/middle_identity.py`: `·, ‧, ⋅, •, ・` 등 중점 변형을 같은 제목 키로 취급하며 raw는 보존한다. 기존 순서 대응은 유지한다. 순서가 다른 일반 영역명은 대표 제목까지 같고 유일한 경우에만 독립 근거 2종으로 연결한다. 서로 다른 구체 과제를 같은 방법명만으로 연결하지 않는다. 영역과 구체 과제문은 별개 원문 관측으로 유지해 대표 제목의 불필요한 충돌을 막는다.
- `scripts/middle_item_scope.py`: 별도 평가표의 학년 근거를 기존 구간 학년 추정과 구별한다.
- `scripts/audit_middle_items.py`: 기존 S5 추출 뒤 별도 평가표를 보완한다. 잘못된 학년의 검토 후보와 같은 셀을 공유할 경우 이전 후보를 귀속 이력으로 남긴다. S4·S5 산출물은 수정하지 않는다.
- `scripts/compare_middle_s6d2d.py`, `scripts/verify_middle_s6d2d.py`, `scripts/validate_middle_s6d2d.py`: 전후 보관·세 회차 재실행·48칸 재대조·새 칸 표본·감사·회귀 재현.
- `services/math-assessment-api/tests/test_middle_s6d2d.py`: 학교 독립 합성 32개. 구간 밖 양성·다른 과목 음성, 전학년·전과목·학기 행 필터, 학년 미정, 학기 충돌, 조사 단편 음성, 빈 제목·영역 제목에서 구체 과제로 보강, 명시적 수행과제와 PDF 영역 머리글의 충돌 방지, 첫 번호 과제, 중점 5종 연결과 잘못된 공통 영역 연결 음성, PDF 시험 열 제외·부분 범위 추적을 포함한다.

## 4. 개발 참고 48칸 재대조

세 차례 astra 원문 목록과 각 16칸을 다시 대조했다. 제목 정규화 일치 또는 원문 줄 범위와 성취기준 교집합의 동시 일치를 사용하며 대응 근거를 JSON에 남겼다. 판독 불가 3칸은 분모에서 제외한다.

| 참고 표본 | 찾음 전→후 | 놓침 전→후 | 잘못·중복 전→후 |
|---|---:|---:|---:|
| 1차 16칸 | 35→35 | 0→0 | 0→0 |
| 2차 16칸 | 34→34 | 0→0 | 0→0 |
| 3차 16칸 | 27→38 | 11→0 | 1→0 |
| 합계 48칸 | 96→107 | 11→0 | 1→0 |

3차 표본의 찾음은 27/38(71%)→38/38(100%), 정밀도는 27/28(96%)→38/38(100%)다. 48칸 합계는 찾음 96/107(90%)→107/107(100%), 정밀도 96/97(99%)→107/107(100%)다. 이미 개발 참고로 사용한 칸의 재대조이며 독립 성능 측정으로 해석하지 않는다.

연평의 대표 제목은 원문 `<책 제목>`을 포함한다. 순천연향 중2 1학기의 세 대표 제목은 최종 실값을 따로 확인했고 모두 `present`다. ‘고체·기체의 용해도와 관련된 다양한 현상을 해석하고, 일상생활 사례에 적용하여 설명한다.’, ‘광물이 없을 경우 생활과 기술의 변화 서술하기’, ‘과학 포트폴리오’다. PDF의 기존 영역 머리글은 명시적 수행과제 셀과 별도 관측으로 보존하며 제목 충돌로 만들지 않는다. 원문의 서술형 어미를 ‘하기’로 새로 쓰지 않는다.

전체 칸별 전후와 항목 대응은 `2026-11-09-s6d2d-recheck.{md,json}`, 회차 지표는 `2026-11-09-s6d2d-comparison.{md,json}`에 있다.

## 5. 네 번째 독립 표본

`docs/dev/2026-11-09-s6d2d-review-sample.md`와 `.json`.

앞 48칸을 제외한 보충 두 회차 잔여 32칸 전체에서 새 seed `2026110947`로 16칸을 비복원 단순무작위 추출했다. bounded 유무는 추출 조건이 아니다. 일반 판본 선택 규칙에 따른 대표 판본 하나를 사용한다. 1절에는 원문 문서·자식·변환 경로·학년·학기·참고 범위만 있고, 수행평가 목록과 파이프라인 값은 없다. 1절 머리에 **과학 구간 밖 평가표가 있을 수 있으므로 문서 전체를 확인한다**고 명시했다. 해당 학년의 대표 원문 문서 전체 목록도 제공한다. 2절에만 파이프라인 bounded를 실었다. 이 표본의 독립 확인은 아직 수행하지 않았다.

## 6. 새 위험·남은 한계

- 문서 전체 탐색 범위가 넓어져 과목·학년·학기 근거와 요약·세부 연결의 오귀속 위험이 증가한다. 다른 과목 근거, 학년 미정, 학기 충돌, 공통 방법명의 다른 과제, 다중 대응은 확정하지 않도록 제한했다. 새 독립 표본에서 실제 의미를 확인해야 한다.
- PDF 복원은 글자층과 셀 선 기하 및 변환 원문의 유일 대응이 필요하다. 이미지 문서·인식 불가 셀·모호한 대응은 자동 확정하지 않는다. 실제 시험/수행 경계는 bbox 감사로 재확인했다.
- 넓은 명시적 수행과제 셀을 대표 제목으로 쓰므로 기존 짧은 영역명보다 제목이 길어질 수 있다. 문장을 요약·개작하지 않았다.
- S5 대상 학년·학기 근거가 전혀 없는 문서는 이 보완 경로로 새로 확정하지 않는다. 교육과정 코드에서 학년을 역산하지 않는다.
- 원문 불일치와 교과서·성취기준 매핑의 교육적 타당성을 확정하는 작업은 포함하지 않았다.

## 7. 검증

최종 전체 회귀는 gold 이름의 합성 테스트를 포함하며 `-p no:cacheprovider`를 적용했다. 금지 정답 자료와 S6d-3b 새 필드 표본은 접근 차단한 상태다. 시작 기준은 961개 중 943 통과·기존 실패 18이며 합성 32개를 추가했다. **최종 993개 중 975 통과·동일한 기존 실패 18·새 실패 0·금지 접근 위반 0**이다.

`py -3` 런처가 샌드박스에서 설치된 Python을 찾지 못하므로 세션 내 `py` 래퍼가 기존 `.venv/Scripts/python.exe`에 연결되도록 했다. 설치·시스템 설정 변경은 없다. 회귀 중 엄격한 소켓 bind 차단이 Windows asyncio 내부 IPC까지 막은 진단 실행은 `data/derived/s6d2d/pytest-strict-ipc-attempt.{json,log}`에 보존했다. 기존 기준과 동일하게 내부 루프백 IPC를 허용하고 외부 DNS·연결과 금지 파일은 계속 차단한 최종 실행으로 비교했다.

```powershell
py -3 scripts/verify_middle_s6d2d.py before
py -3 scripts/compare_middle_s6d2d.py
py -3 scripts/verify_middle_s6d2d.py after
py -3 scripts/validate_middle_s6d2d.py
```

감사에는 기존 필드 소유·오프셋·원문·코드·판본·자유학기 범위 검사에 더해 평가표 과목/학년/학기 근거, 전과목 행의 실제 문맥, PDF 셀 bbox와 원문 값 대응을 포함한다. 변환 text 323개 해시, 이전 결과 6개 해시, 표본 32→16 및 앞 48칸 제외 재현, 1절 값 누출, 파이프라인 재현을 검사한다. 학교명·학교코드·파일명·변환 경로·해시 및 좌표 분기 하드코딩 grep도 수행한다.

**최종 감사 오류·금지 접근·명시적 과제/머리글 제목 충돌·조사로 시작하는 bounded 제목·하드코딩 grep 모두 0**이다. 변환 text 323개와 보관본 지표·표본 재현도 모두 일치한다. 변경 Python 11개 ruff 통과, `git diff --check` 통과이며 status·stat를 변경 파일 목록과 대조했다. 추적 파일 diff는 5개·139줄 추가·23줄 삭제이며, 신규 코드/테스트 6개와 개발 보고 8개는 미추적으로 표시된다.

감사·회귀 결과와 이전 결과 해시는 `data/derived/s6d2d/validation.json`, 회귀 로그는 `data/derived/s6d2d/pytest-{before,after}.{json,log}`다. 변경 Python 전체 ruff와 `git diff --check`, `git status --short`, `git diff --stat`를 실행했다. git diff stat에는 추적 중인 기존 파일만 나오므로 신규 파일은 status와 함께 대조한다.

시작 전부터 있던 미추적 `data/.gold-before-acl-fix/`, `data/gold/`, `data/reference/gold_label_schema.json`, `data/rosters/`는 이번 변경과 구분했다. 원문·정답 자료·새 필드 표본·설치·패키지 파일·DB/API/웹·배포·커밋은 변경하지 않았다. 최종 산출물 폴더는 일반 mkdir로 만들었고 tempfile 산출물 폴더를 사용하지 않았다.
