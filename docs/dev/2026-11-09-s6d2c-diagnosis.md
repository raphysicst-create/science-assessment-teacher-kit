# S6d-2c 착수 진단

S6d-3 현재 결과를 먼저 확인했다. 두 번째 독립 확인의 0건은 당시 표본에 저장된 결과이며, 현재 결과와 구별한다. 학기 코드는 네 칸 모두 본문·파일명에서 해당 학기로 확인된다.

| 칸 | 현재 후보·검토 사유 | 일반 원인 | 보강 방향 |
|---|---|---|---|
| S03 흥해 중2 2학기 | 항목 구조 미식별, 요약표 55·세부표 57 전체가 불완전 구조 검토 | 변환 HTML의 빈 rowspan 셀이 실제 값 셀과 충돌하여 표 전체를 버림. 요약 영역·시기·코드와 두 세부 과제는 원문에 존재 | 빈 선행 셀의 겹침만 별도 진단하고 값 셀의 좌표를 보존. 값이 있는 선행 셀의 겹침은 계속 검토. 표 안 가·나 과제 머리글도 연결 |
| S07 울산제일 중1 1학기 | 요약 열 2개와 세부표 후보에 원문 제목 셀 미확정 | 요약의 평가유형 칸에 과제명이 있으며 세부 라벨 앞에 ➊·➋가 붙음 | 장식 번호를 라벨 판별에서 제거, 방법 칸의 구체 활동을 제목으로 인식. 상·중·하 무점수도 허용 |
