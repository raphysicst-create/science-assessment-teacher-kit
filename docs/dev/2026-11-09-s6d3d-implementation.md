## 2. 바꾼 파일과 일반 규칙

- `scripts/middle_fields.py`에서 척도·채점기준의 병합 폭, 행에 놓인 수준, 다음 행의 점수, 기준 문장에 섞인 A~E·수치 점수를 읽는다. 최소 두 수준/점수 관측과 판단 문장을 요구한다. 명시된 채점기준 안의 복수 질문 체크리스트도 보존한다. 요소별 수준 점수는 같은 요소의 최고 관측값을 사용하고, 새로운 요소의 배점과 모든 근거 범위를 남긴다. 요소명·점수의 전치 행도 처리한다. 활동 동사가 있는 소유 요소와 첫 기준 문장을 설명으로 보강한다.
- 같은 파일에서 평문의 명시적 제목 다음 라벨/값 블록을 읽는다. 과제 개요·설명, 방법, 성취기준, 요소별 괄호 배점, 두 수준 이상의 채점기준을 원문 범위로 남긴다. 표 경계가 소실된 항목은 review로 유지한다.
- `scripts/middle_items.py`에서 과제 개요·활동 개요·주요활동·척도·기대수행·수행특성 라벨을 추가했다. 제목이 확인된 form 뒤의 채점표는 공백·페이지 표지·채점기준 소제목·페이지 번호를 사이에 두고 연결할 수 있다. 새 과제·학년·학기·성취기준 표지는 보류 조건이다. 머리글 없는 후속 표는 페이지 표지, 유일한 앞 form, 일치하는 기준/수준 열, 모든 행의 판단·수준 쌍을 요구한다. 연결 근거와 실제 앞 머리글 위치를 보존한다.
- `scripts/assessment_symbols.py`에서 변환된 체크 기호 `∨`를 선택 기호로 추가했다. 방법 셀 안의 명시적 선택지만 읽는다.
- 규칙 버전은 `middle-items-v15`, 항목 ID 버전은 기존 v2다. 과제명·학교명·학교코드·파일명·해시·특정 좌표 분기는 추가하지 않았다.
- 재현 도구 4개는 `scripts/compare_middle_s6d3d.py`, `scripts/recheck_middle_s6d3d.py`, `scripts/verify_middle_s6d3d.py`, `scripts/validate_middle_s6d3d.py`다. 합성 테스트는 `services/math-assessment-api/tests/test_middle_s6d3d.py` 26개다.

## 5. 새 위험과 남은 범위

- 점수·등급 토큰이 기준 문장에 섞인 변환을 허용하는 범위가 넓어졌다. 명시적 채점/수준 머리글, 판단 문장, 서로 다른 두 수준/점수를 요구한다. 일부 결합 셀은 기준과 요소의 분리를 확정하기 어려워 계속 unconfirmed다.
- 앞 form의 소유를 잇는 연결은 새 제목·성취기준·학년·학기 또는 열 불일치에서 보류한다. 과제명만 비슷하거나 코드만 공유하는 6건, 복수 후보 7건은 진단 후보로 남는다. 긴 일반 문단을 가로지르는 연결은 여전히 근거가 부족하다.
- 실제 평문 진단 후보 4건은 이번에 회수되지 않았다. 명시적 라벨 블록의 평문 지원은 합성 테스트로 검증했지만, 실제 후보에는 일반 평가방침과 과제 범위의 혼재가 남아 있다. 개발 표본의 설명 3건 누락·2건 부분 누락, 방법 1건 누락·2건 불일치도 남아 있다.
- 이 수치는 열린 개발·보충 자료의 결과다. 처음 보는 학교 양식의 회수율은 별도 확인이 필요하다.

## 6. 검증

전체 회귀는 gold 이름의 합성 테스트를 포함했고 `-p no:cacheprovider`를 적용했다. 시작 1,115개 중 1,097 통과·기존 18 실패에서 최종 1,142개 중 1,124 통과·같은 18 실패다. 새 실패 0건이다. 새 파일의 합성 26개와 선택 기호 사전으로 매개화되는 기존 테스트 1개가 늘었다. 기존 테스트의 기대값은 수정하지 않았다.
