## 2. 바꾼 파일·규칙

- `scripts/middle_items.py`: 규칙 버전 `middle-items-v14`. `영역 및 방법`의 제목/방법 행을 구별하고 동일 제목 병합셀 아래 배점을 합산한다. `aggregation=sum_sibling_allocations`, 구성값, 원문 evidence를 함께 보존한다. 총점이 인쇄되어 있으면 우선하며 단위 충돌을 합으로 덮지 않는다. 처리 규정 표/행·단원 나열·단원 번호·일반 성취수준표 음성을 강화했다. 구체 영역명 뒤의 완전한 `반영비율 N%` 문법을 원문 부분 범위로 분리하고, 명시 영역 라벨과 성취기준이 있는 짧은 제목을 허용했다. 항목 ID 버전은 v2를 유지한다.
- `scripts/middle_fields.py`: 구분자가 사라진 방법 선택지라도 방법 어휘가 셀 전체를 소비할 때만 방법으로 인식한다. 활동 문장 일부에 방법 단어가 있다는 이유만으로 제외하지 않는다.
- `scripts/middle_identity.py`: 대표 제목이 없는 form은 요약의 동일성 경쟁자로 사용하지 않는다. 기존의 문서·학년·학기 범위, 순서·문자 그대로 제목·시기·배점·코드 근거 기준은 유지한다. 대전대화의 두 학기는 정확한 과제명과 완전한 열/상세 순서가 대응하여 연결됐고, 상세에 요약의 20점·20%가 참조된다. 실험 과제는 방법 두 값이 남는다.
- `scripts/compare_middle_s6d2f.py`: 세 회차 보관·재실행, 다섯 표본 80칸 재대조, 보충 bounded 전체 의심 목록 생성. 새 독립 표본 생성은 호출하지 않는다.
- `scripts/verify_middle_s6d2f.py`, `scripts/validate_middle_s6d2f.py`: 금지 자료·외부 네트워크 guard, 전체 회귀 전후 비교, 채점기 테스트 실패 별도 집계, 원문·필드·기하·합산·보관본·재대조·의심 목록 재현 감사.
- `services/math-assessment-api/tests/test_middle_s6d2f.py`: 학교 독립 합성 22개. 하위 열 합/다른 상위 제목 분리, 두 방법, 상세 연결, 인쇄 총점 우선, 잘못된 단위 음성, 규정 표·행, 붙은 방법 및 체크 행, 단원 나열/번호 음성·독립 과제 양성, 비율 부분 범위, 짧은 영역과 불완전 상세를 검사한다.

## 6. 새 위험·남은 한계

- 짧은 명사 나열에는 실제 과제명도 있을 수 있다. 활동 어휘가 있으면 나열 음성에서 제외하지만, 동사 없는 실제 활동명은 검토로 이동할 수 있다.
- 짧은 영역명 허용은 명시 영역 라벨과 성취기준이 있을 때로 제한했다. 원문이 끊긴 `열` 상세는 검토로 남고, 범위가 입증된 요약 항목으로 찾았다. 상세 내용을 임의로 합성하지 않았다.
- 하위 열 합산은 한 제목 셀이 전체 열을 소유하고 각 열에 같은 행의 배점이 하나씩 있을 때만 적용한다. 잘못된 단위·인쇄된 총점·여러 채점 수준이 있는 경우는 합산하지 않는다. 인쇄된 모든 부분이 실제 총점을 완전히 구성한다는 교육적 타당성까지 인증하지 않는다.
- 일반 방법/영역명 뒤에 비율만 붙은 셀은 모호함을 유지한다. `탐구활동/프로젝트/포트폴리오 반영비율 …`을 제목 분리만으로 새 bounded 항목으로 승격하지 않는다. 원문 학년 표지가 빠진 부분을 코드 의미로 재귀속하지 않았다.
- 80칸의 항목 대응 지표와 제목·방법·배점·코드 각 필드의 정확도는 구별해야 한다. 판독 불가 4칸의 유무·개수는 미확정이다.

## 7. 검증

전체 회귀는 gold 이름의 합성 테스트를 포함하여 `-p no:cacheprovider`로 실행했다. 시작 **1,093개 중 1,075 통과·기존 실패 18개**, 최종 **1,115개 중 1,097 통과·동일한 기존 실패 18개·새 실패 0개**다. 신규 합성 22개는 모두 통과했다. 다른 작업자 담당 `test_gold_score.py`의 실패는 **0개**이며 `gold_score_failures`에 별도 기록했다.

원문 추적·필드 소유권·요약 참조·학년/학기/과목·PDF 셀 기하·하위 열 산술·보관본·80칸 재대조·의심 목록 재현 감사 위반은 **0**이다. 변환 text 323개의 해시를 확인했다. 금지 자료 접근·외부 네트워크·학교/코드/파일명/해시 하드코딩 grep·좌표 분기 grep은 **0**이다. 회귀에 필요한 Windows asyncio 내부 루프백 IPC만 기존 guard 기준으로 허용한다.

변경 Python 7개 ruff와 `git diff --check`가 통과했다. `git status --short`, `git diff --stat`를 변경 목록과 대조했다. 새 파일은 미추적 상태라 `git diff --stat`에는 기존 Python 3개의 변경만 보인다. 시작 전부터 있던 gold 관련 미추적 경로·명부는 이번 변경과 구분했고 열지 않았다. 시작 시 다른 작업자의 채점기·테스트 변경을 확인했으며 해당 파일을 직접 편집하지 않았다.
