# S6d-3c 요약 수치 병합과 필드 상태 정리

## 1. 바꾼 파일과 일반 규칙

- `scripts/middle_items.py`에서 행형 요약표를 열형보다 먼저 판별하고 rowspan 머리글 다음 행부터 읽는다. 평가방법 칸의 수행/정기시험 구분을 문맥으로 사용하고 합계 행을 제외한다. `학기말 반영비율(%)`, `배점(만점)`, `반영비율(배점)`과 비율→점수 순서의 복합 셀을 처리한다. 모든 값과 머리글은 변환 원문의 문자 범위를 보존한다.
- `scripts/middle_identity.py`에서 완전한 요약 행/열 순서와 세부 순서 일치에 실제 과제명 일치 또는 유일한 영역명 일치를 추가 근거로 인정한다. 영역명과 과제명이 같은 관측이면 한 표로 센다. 기존 문서·자식·판본·학년·학기·과목 경계를 유지하고 다중 대응을 보류한다. 제목 외 근거가 한 종류이면 동일성 검토 후보로 남긴다.
- 연결 뒤 시기·만점·비율이 세부에 없으면 `value_source=summary`와 요약 항목 ID로 참조한다. 원래 세부 값·상태·근거와 요약 관측을 `source_observations`에 보존한다. 두 값이 다르면 conflict, 같으면 equal로 표시한다. 명시적 빈 요약 칸의 부재 근거도 연결된 세부에 참조할 수 있다.
- `scripts/middle_items.py`의 대표 제목은 구체 과제명 > 영역명 > 번호 순이다. 같은 종류 안에서는 명시적 과제/제목 칸, 구체 영역 칸, 머리글, 요소에서 보강한 활동 순으로 선택하고 마지막 동률은 원문 순서로 푼다. 구체 수행과제 칸의 ‘수 있다’ 문장을 그대로 허용하며 짧은 일반 문장은 거부한다. 충돌의 `observed_values`, status, 원문 관측을 보존하면서 대표 제목을 남긴다. 갈래 머리글은 `assessment_area`에 보존한다. 규칙 버전은 `middle-items-v12`, 항목 ID 버전은 기존 v2다.
- 같은 파일에서 번호 과제 머리글, 작은 성취기준/성취수준 머리글 표, 표 사이 코드, 바로 뒤 방법·요소·채점기준 표의 연속성을 확인해 분할된 세부표를 연결한다. 새 과제·학년·학기 머리글을 넘지 않는다. 일반 성취수준표는 성취기준·성취수준 문맥으로 구별한다.
- `scripts/middle_fields.py`에서 소유가 입증된 빈 칸, 과제 전용 수준제 척도, 요소별 배분이 없는 통합 체크리스트를 `source_absent`로 표시하고 `absence_basis`, `absence_evidence`에 근거와 위치를 남긴다. 교육과정의 앞쪽 A~E 수준, 판독 불가 값, 근거 없는 필드는 unconfirmed다. 통합 점수의 번호 목록은 요소별 배점 부재로 표시한다. 평가척도·평가요소(점수) 라벨도 읽는다.
- `scripts/audit_middle_items.py`, `scripts/compare_middle_items.py`에서 원문 후보가 보존된 제목 conflict의 대표값을 감사한다. 일반 필드의 conflict 확정값은 계속 위반으로 센다.
- 재현 도구는 `scripts/compare_middle_s6d3c.py`, `recheck_middle_s6d3c.py`, `verify_middle_s6d3c.py`, `validate_middle_s6d3c.py`다. 합성 테스트는 `services/math-assessment-api/tests/test_middle_s6d3c.py` 36개다. 기존 `test_middle_s6d2.py`, `test_middle_s6d3.py`의 제목 conflict 빈칸 기대 두 곳은 요청한 대표값 보존 규칙으로 바꾸고 이유를 주석에 적었다.

## 5. 새 위험과 남은 누락

- 제목/영역과 완전한 순서를 연결 근거로 인정하는 범위가 넓어졌다. 같은 이름이 반복되거나 순서·개수가 어긋나면 기존 다중 대응/검토 상태로 남긴다. 독립 확인에서 실제 동일성을 더 확인해야 한다.
- 제목 conflict에는 대표 표시값이 있으므로 소비자는 표시값과 status를 함께 봐야 한다. 구체 수행과제 원문을 사용해 제목이 길어질 수 있다.
- 수준제·통합 체크리스트의 source_absent는 소유가 입증된 표의 근거다. 뒤쪽 미연결 표의 수치 존재 여부는 미확인으로 남았다. 출처별 관측과 부재 근거를 따로 남겼다.
- A01의 공유 요약 제목과 세부 미연결, A09의 뒤쪽 분할표, B05의 척도(점수) 배점 열 인식, 위의 설명 부분 누락과 B10 방법 누락이 남았다. 새 표본의 상대 표 7건과 C08 별도 요약표 미확인도 남은 한계다.

## 6. 검증

전체 회귀는 gold 이름의 합성 테스트를 포함한다. `-p no:cacheprovider`를 적용했고, 시작 993개 중 975 통과·기존 18 실패에서 최종 1,029개 중 1,011 통과·동일한 18 실패·새 실패 0이다. 추가 합성 36개가 모두 통과했다. 기존 두 기대값 변경은 제목 conflict에도 대표 제목을 남기라는 요청을 반영했다.

세 회차 소유·원문 오프셋·필드 범위·코드·정책 범위·평가표 과목/학년/학기·PDF 기하 감사, 부재 근거와 소유, 대표 제목 원문 추적, 표본 재현과 1절 값 누출 감사를 실행했다. 323개 변환 text 해시와 이전 결과 6개 해시를 검증했다. 정답 자료·금지 독립 표본과 외부 연결은 실행 guard로 차단했다. Windows asyncio의 내부 루프백 IPC는 기존 회귀와 동일하게 허용했다.
