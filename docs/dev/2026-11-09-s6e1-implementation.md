# S6e-1 AI 읽기 보완 단계 구현

2026-11-09

## 목적과 경계

처음 보는 문서 양식에서 규칙이 놓친 중학교 과학 수행평가를 보완하는 시험 단계다.
규칙 결과를 보존하고 원문 대조를 통과한 AI 결과를 추가 후보로 저장한다.
실제 AI 호출과 네트워크 사용은 수행하지 않았다. 실제 성능 수치는 측정하지 않았다.

구현 파일은 `scripts/middle_ai_read.py`, 한국어 지시문은
`scripts/prompts/middle_ai_read_v1.md`, 합성 테스트는
`services/math-assessment-api/tests/test_middle_s6e1.py`다.

## 단계와 산출물

모든 명령은 `--round-key`를 받는다. 기본 산출물 폴더는
`data/derived/ai_read/<round>/`이며 일반 `mkdir`로 생성한다.

| 단계 | 처리 | 산출물 |
|---|---|---|
| targets | S4 문서와 S5 과학 구간을 읽어 문서 기준 대상 생성 | targets.jsonl, prompts/*.md, summary.json |
| run | stdin 지시문으로 Codex 실행, 감사, 유효한 응답 이어 하기 | responses/*.json, *.events.jsonl, *.status.json, *.stderr.txt, run.json |
| verify | 원문 해시·제목·인용·줄·학년·학기를 대조하고 중복 제거 | verified.json |
| merge | 규칙 후보와 관계를 대조하고 검증된 새 후보 추가 | data/derived/items_ai/<round>.json |
| evaluate | 개발 참고 80칸 중 해당 회차 40칸을 세 방식으로 대조 | evaluation.json, evaluation.md |

S4에 이미 독립 문서로 기록된 ZIP 자식은 자식의 변환 JSON과 좌표계를 사용한다.
S4·S5·S6 모듈과 원래 산출물을 수정하지 않는다.

### 대상 선정

- S5 과학 구간이 있는 단일 교과 문서는 전체 본문을 준다.
- 다교과 문서는 과학 구간마다 앞뒤 80줄을 포함하고 겹치는 창을 합친다.
- S5 과학 구간이 없는 문서는 과학 교과 표지가 있는 표 전체를 선택한다.
  표 경계를 식별하지 못하면 표지 앞뒤 60줄을 선택한다.
- 교과 표지는 HTML 셀 전체·첫머리, Markdown 셀 전체·첫머리, 과목 제목,
  교과명 나열로 한정한다. 본문 속 일반적인 과학 관련 표현만으로 선택하지 않는다.
- 파일명이 다른 단일 교과를 가리키는 경우와 본문·표지가 없는 경우는 이유를 남긴다.
- 문서의 학년을 미리 확정해 대상에서 제거하지 않는다. 중3 결과는 검증 후 범위 밖으로 분리한다.
- 각 조각은 원문 60,000자 이하이며 줄 경계를 유지한다. 다음 조각은 직전 조각의
  끝부분을 최소 3,000자 포함한다. 줄 길이에 따라 겹침이 더 길어질 수 있다.
  60,000자를 초과하는 단일 줄은 조용히 자르지 않고 오류로 중단한다.
- 줄 번호는 원래 문서 기준 1부터 시작한다. `char_count`는 줄 번호와 지시문을 제외한
  원문 글자 수이며 중복 창·조각의 겹침도 포함한다. `prompt_chars`는 메타데이터와 지시문까지 포함한다.
- 메타데이터 후보는 S4·S5의 문서 전체 후보와 근거를 모은다. 후보가 하나일 때만
  `metadata` 근거를 허용한다. 조각 범위만으로 학년·학기 후보를 좁히지 않는다.

### 실행과 감사

실제 실행 명령은 지정된 Codex 경로의 `exec --strict-config --skip-git-repo-check
-s read-only -C <격리 폴더> --json -o <답 파일> -`다.
모델 인자를 추가하지 않는다. 기본 설정 및 선택된 기본 프로필이 `gpt-6-astra`이면 거부한다.
이벤트에 기록된 모델명도 확인한다. 기본 동시 실행 수는 4이고 호출별 제한은 900초다.

`--isolated-cwd`는 필수이며 실제로 존재하는 빈 폴더여야 한다.
심볼릭 링크를 해소한 경로가 `D:/workspace` 안이거나 그 상위이면 거부한다.
격리 폴더에 원문이나 지시문 파일을 복사하지 않고 지시문은 stdin으로만 전달한다.
답과 로그는 해당 회차의 `responses/`에 저장한다.

감사에서 허용하는 이벤트는 `thread.started`, `turn.started`, `turn.completed`,
`turn.failed`, `error`, `item.started`, `item.updated`, `item.completed`다.
수동 출력 항목은 `agent_message`, `reasoning`, `todo_list`다.
`command_execution`, `file_change`, `file_read`, `file_search`, `web_search`,
`mcp_tool_call`, `tool_call`, `function_call`, `computer_call`, `image_view`,
`shell_command`, `exec_command`, `read_file`, `collab_tool_call`은 도구 실행으로 무효 처리한다.
중첩 객체의 도구 유형·실행 페이로드도 확인한다.

알 수 없는 이벤트·항목 유형은 유형별 횟수와 함께 `감사 불명`으로 무효 처리한다.
JSON 로그 오류, 종료 이벤트 누락, 호출 실패, 시간 초과, 답 JSON 오류도 무효다.
동일 지시문 해시, 답 해시, 이벤트 해시와 재감사가 모두 유효한 경우에만 건너뛴다.
재시도 전에 이전 답을 비워 실패 후 이전 답이 재사용되는 것을 방지한다.

`--fake-responses <폴더>`는 `<target_id>.json`과 `<target_id>.events.jsonl`을 읽는다.
가짜 응답도 같은 감사를 통과해야 한다. 검증·병합·평가 산출물에는 `simulated`를 기록한다.
`--dry-run`은 실행할 명령만 출력하고 응답 산출물을 쓰지 않는다.

### 원문 검증과 오프셋

제목은 `title_line`의 실제 원문에 있어야 하고, 그 줄이 적어도 하나의 근거 줄 범위에
포함되어야 한다. 모든 인용은 각자 지정한 줄 범위 안에서 일치해야 하며 1–200자다.
모든 줄 번호와 학년·학기 근거 줄은 해당 조각 안에 있어야 한다.

비교에는 NFKC, 공백 접기, `<br>`의 공백 처리, 나머지 태그 제거와 HTML 엔티티 해제를
사용한다. 정규화한 각 글자에서 원문 글자 구간으로 역매핑한다.
NFKC로 여러 글자가 되는 문자 일부만 매칭한 경우 원래 문자의 전체를 인용으로 인정하지 않는다.
한글 자모 조합, 결합 문자, CRLF, 이모지를 포함한 합성 테스트로 좌표를 확인한다.
원문·locator의 `raw`는 수정하지 않는다.

학년·학기 인용에는 해당 값을 가리키는 표지가 있어야 하며 복수 표지는 실패다.
`metadata`는 문서 전체 후보가 요청 값 하나일 때만 통과한다.
하나라도 실패하면 과제를 버리고 이유를 남긴다. 중3은 `out_of_scope`로 분리한다.
같은 문서·ZIP 자식·학년·학기의 정규화 제목이 같고 근거 위치가 겹치면 하나로 합친다.

locator는 S6의 `text_locator`를 재사용하며 유니코드 코드포인트 오프셋과 끝 제외 규칙을 따른다.
원문을 다시 읽어 S4 해시를 확인한다. 병합 시에도 원문과 실행·지시문 바인딩을 재확인하고,
대상이나 답이 바뀌었으면 재검증을 요구한다. 평가도 사용한 규칙·검증 결과의 해시를 확인한다.

### 병합

같은 문서·ZIP 자식·학년·학기에서 근거 위치와 규칙 수행 후보의 위치가 겹치는지를 확인한다.

- AI 한 과제와 규칙 한 항목은 `agrees`로 기록하고 규칙의 bounded 여부를 보존한다.
- 여러 AI 과제가 하나의 미확정 규칙 후보에 겹치면 새 항목을 만들고
  `ai_relations.ai_split_suggested`에서 규칙 항목 ID와 AI 과제 ID들을 연결한다.
- 여러 AI 과제가 bounded 항목에 겹치면 `conflict`로 기록한다.
- 하나의 AI 과제가 여러 규칙 항목에 겹치는 추가 모호성도 `conflict`로 보류한다.
- 겹치는 규칙 후보가 없으면 새 항목을 만든다.

규칙 항목 객체는 필드 추가 없이 그대로 복사한다. 분할 표시는 `ai_relations`에서 해당 ID에 붙인다.
기존 보고서의 규칙 집계도 유지하고 추가 건수와 관계 수는 `ai_read_summary`에 분리해 기록한다.
새 항목은 `performance`, `ai_verified`, `ai_read`, `public_eligible=false`를 사용한다.
제목만 `present`이며 나머지 필드는 모두 `unconfirmed`와
`AI 읽기 1단계: 필드 미추출` 사유를 갖는다.

### 개발 참고 평가

개발 참고 파일은 지정된 날짜 패턴의 다섯 표본에서 동적으로 찾는다.
총 80칸이며 회차별 40칸이다. `*-check.md`의 칸별 참고 개수가 있으면 우선 사용하며
총괄 메모와 과거 규칙 판정을 함께 보존한다. 과거 규칙의 찾음 수를 현재 규칙의 지표로 재사용하지 않는다.

AI 단독, 규칙 bounded, 규칙 bounded와 AI 새 항목의 합집합을 각각 계산한다.
정규화 제목·별칭의 일대일 일치만 자동 찾음으로 계산한다.
제목이 다르지만 고유한 근거 줄이 겹치는 경우는 총괄 확인 제안으로 남긴다.
따라서 표현이 다른 같은 과제는 잠정 놓침·오검출로 표시될 수 있다.
판독 불가 칸은 분모에서 제외하며 확정 0건으로 취급하지 않는다.
AI 추가 발견, 오검출 의심, 놓침 의심을 유형별 표와 총괄 확인 표로 출력한다.
참고 목록의 항목 수준 판정과 AI 추출이 다르면 사람이 원문으로 확정해야 한다.

## 맹검

대상 생성과 실행은 회차 키에 `gold`가 있으면 거부한다.
읽기·쓰기 경로도 해소한 뒤 `data/gold/`, `docs/gold/`, `*-gold*`,
`.gold-before-acl-fix` 접근을 거부한다.
정답 자료와 채점기 코드는 열람하지 않았다. 지시문과 검증 규칙에 실제 학교명,
파일 해시나 개발 참고 과제 제목을 넣지 않았다.

## 검증 기록

- 합성 테스트 63개 통과. 두 회차의 가짜 응답으로 실행·이어 하기·검증·병합·평가 흐름을
  확인했다. 실제 subprocess와 네트워크 연결을 차단한 테스트다.
- 호출 시간 초과는 subprocess 대역으로 재현했다. 실제 Codex 프로세스는 실행하지 않았다.
- 회귀는 `-p no:cacheprovider`로 1,099개 통과, 기존 API·데이터 실패 18개였다.
  새 실패는 0개였다. `test_gold_rules.py`와 `test_gold_s9.py`의 합성 테스트를 포함했다.
- `test_gold_score.py`는 `scripts/gold_score.py`를 import해 실행하므로 제외했다.
  사용자 지시의 채점기 실행 금지와 gold 테스트 포함 전체 회귀 요구가 충돌하여,
  합성 테스트에 한한 실행 허용 여부를 사용자에게 요청했다. 해당 답변은 아직 대기 중이다.
  따라서 채점기까지 포함한 전체 회귀는 완료하지 못했다.
- 회귀 프로세스의 감사 훅으로 실제 정답 자료와 정답 회차 경로 접근, 채점기 로드를 차단했다.
- `py -3`는 설치된 Python을 찾지 못해 기존 `.venv/Scripts/python.exe`를 사용했다.
- 변경 Python 파일에 대한 ruff가 통과했다. `git diff --check`와 새 파일별 whitespace 점검을 수행했다.
- 155개 실제 조각의 지시문 해시, 원문 줄 경계, 글자 수, 오프셋을 재대조했다.
  조각 ID 중복은 0개다.
- 구현 모듈·프롬프트의 실제 개발 학교명과 64자리 파일 해시 검색은 각각 0건이다.
  모듈의 문자열 리터럴과 개발 참고 과제 제목의 교집합도 0건이다.
- Git 변경 대상은 새 구현·지시문·테스트·이 설계 문서 4개다. 기존 미추적 데이터 항목은
  시작 시 `git status --short` 목록과 대조했다. 실제 대상 산출물은 Git의 기존 제외 규칙에 해당한다.

## 새 위험과 해석 범위

- 실제 Codex를 호출하지 않아 설치된 CLI 버전의 이벤트 형태와 `--strict-config` 호환성은
  실제 실행으로 확인하지 못했다. 새 이벤트 형식은 감사 불명으로 차단된다.
- 이벤트 감사는 CLI가 기록한 행위를 대상으로 한다. 실행 전 기본 설정 검사와
  이벤트 모델 검사만으로 기록되지 않은 런타임 설정까지 증명할 수는 없다.
- 원문 글자 일치는 과제의 교육적 타당성·과학 귀속·서로 다른 표의 동일 과제 여부를 확정하지 않는다.
  이 단계의 모든 AI 항목은 추가 후보이고 공개 불가다.
- 한 줄에 같은 제목·인용이 여러 번 있으면 첫 번째로 원문에 완전히 일치하는 위치를 사용한다.
  넓은 개요표 근거가 여러 항목에 겹치면 충돌이 늘어날 수 있다.
- S5가 놓친 다교과 문서에서 과학 표지가 있는 표만 주면 멀리 떨어진 무표지 세부표가 창 밖에
  남을 수 있다. 대상 정책의 재현율 한계이며 추후 실제 응답으로 점검해야 한다.
- 중3 전용 문서도 표지 기준으로 대상에 들어올 수 있다. 학년을 AI 본문 근거로 판단하도록 한
  대상 정책을 따르며 검증 단계에서 범위 밖으로 집계한다.
- 원문과 실행 바인딩이 변하면 재검증을 요구한다. 여러 단계는 순서대로 실행해야 한다.

## 총괄 실행 명령

저장소 루트의 PowerShell에서 실행한다. `<ISOLATED>`는 `D:/workspace` 밖에 미리 만든
빈 폴더의 절대경로로 바꾼다. 해당 폴더는 실행 중에도 비워 둔다.
