판정: 차단

**2. 차단 사유**

1. **제목 사용 조건이 서로 다릅니다 — 완료 기준 3(b)·3(c).**  
   「0. 두 축 한눈에」는 제목 동사를 다른 근거가 없거나 동률일 때만 사용하지만, 「2. 활동 축 판정 규칙」 R4는 제목을 항상 투표에 포함합니다. 「계산·측정」의 경계 반례 ‘부력 측정 실험’은 제목 표를 제외해야 제시된 판정이 나옵니다. 어느 조항을 적용하는지에 따라 주활동이 달라집니다.

2. **경계 반례의 동률 처리가 R6와 정면으로 충돌합니다 — 완료 기준 3(b)·3(c).**  
   「제작」의 ‘천체티콘 만들기’는 제작 2표·추론·설명 2표에서 제목을 따라 **제작**으로 판정합니다. 그러나 체크 후보는 추론·설명·실험평가이므로 R6에 따르면 동률 활동 중 후보에 들어 있는 **추론·설명**이 주활동입니다. R6에는 제목 우선 예외가 없습니다. JSON에도 같은 모순이 있습니다.

3. **작성의 정의와 전환 조건이 맞지 않고, 영역명 표를 부여하는 규칙도 빠져 있습니다 — 완료 기준 3(a)·3(b)·3(c).**  
   「작성」의 정의는 **글 자체의 질을 채점**해야 한다고 정하지만, R4·R5①은 제목에 ‘일기’만 있어도 작성으로 전환할 수 있습니다.  
   또한 「작성」·「문제해결」의 ‘기후변화가 해수면 상승에 미치는 영향과 이를 해결하기 위한 우리의 역할’은 영역명 ‘과학 글쓰기’를 작성 1표로 셉니다. 하지만 체크가 있으므로 R3의 영역명 대체 경로는 적용되지 않고, R4의 투표 대상에도 평가영역은 없습니다. 사례에만 존재하는 추가 규칙입니다.

4. **관찰 표지의 기본 활동 안내가 모순됩니다 — 완료 기준 3(b).**  
   「체크값·평문 방법 표지 분류」와 R1은 ‘관찰 평가’·‘관찰·기록’을 활동 근거가 아닌 `scorer_marker`로 정합니다. 반면 「과정평가」의 ‘기본으로 가리키는 체크값’과 JSON의 해당 `checkbox_defaults`에는 두 표지가 들어 있습니다. 라벨러와 기계가 참조할 기본 대응표가 일치하지 않습니다.

5. **경계 반례의 보조활동이 R8과 일치하지 않습니다 — 완료 기준 3(c).**  
   「발표·토론」의 ‘나만의 주기율표 만들기’는 실험·실습 체크가 있는데도 보조활동에서 **실험평가**를 빠뜨립니다. R8은 주활동을 제외한 체크 기본 활동을 모두 저장하도록 합니다.  
   「과정평가」의 ‘포트 폴리오’도 설명에는 **제작 1표**라고 적고 JSON의 `secondary`는 빈 배열입니다. 그 표를 인정하면 제작을 보조로 넣어야 합니다. 또한 제시된 ‘구성·가독성’은 제작 사전에 없어, 표의 근거도 재현되지 않습니다.

**3. 규칙 모순·정의 겹침 의심**

아래 기대 답은 교육 판단의 확정이 아니라, 명시된 공통 규칙 또는 정의에 따른 검수 기대값입니다. 문서 사례는 문서가 제시한 정보만 사용했습니다.

| 구체 사례 | 규칙을 그대로 적용한 답 | 기대하는 답·충돌 지점 |
|---|---|---|
| **문서: ‘부력 측정 실험’**. 체크는 서·논술+실험·실습, 요소는 측정 1표·서술 1표 | R4의 제목 ‘측정’ 1표를 더하면 계산·측정 2 : 추론·설명 1. R6 → **계산·측정** | 사례는 **추론·설명**. 제목을 항상 셀지, 보충 근거로만 쓸지 통일해야 함 |
| **문서: ‘천체티콘 만들기’**. 사례에 명시된 제작 2 : 추론·설명 2를 그대로 사용 | R6 → 후보 집합에 포함된 **추론·설명** | 공통 규칙 기준 기대 답도 **추론·설명**. 사례의 **제작**과 충돌 |
| **문서: 해수면 상승과 우리의 역할**. 서·논술 체크, 영역명 ‘과학 글쓰기’ | R3·R4에는 이 영역명에서 작성 표를 얻는 경로가 없음. 따라서 제시된 **작성 전환을 재현할 수 없음** | 작성 판정을 유지하려면 영역명 사용 조건을 공통 규칙에 명시하고 작성 정의와도 맞춰야 함 |
| **가상:** 제목 ‘과학 일기 쓰기’, 서·논술 체크. 채점 문장은 ‘열의 이동 원리를 설명한다.’, ‘입자 모형으로 예측한다.’ 두 개이며 글 형식은 채점하지 않음 | 작성 1표·추론·설명 2표지만 R5① → **작성** | 작성 정의에 따르면 **추론·설명**. 산출물 형식과 글의 질 평가를 구별해야 함 |
| **가상:** 방법·체크 없음, 제목 ‘활동 A’, 유일한 채점 문장 ‘안전한 대피 방안을 제안한다.’ | ‘안전’으로 실험평가 1표, ‘방안을’·‘제안’으로 문제해결 1표. R7 → **기권** | 정의 기준 **문제해결**. 실험 수행이 없는 안전 제안까지 실험평가 표가 생김 |

정의의 겹침도 운영 기준이 필요합니다. 예를 들어 가상 문장 **“가설을 설정하고 실험을 수행하며 결론을 도출한다.”**는 R4상 한 문장이므로 탐구 1표·실험평가 1표입니다. 이를 세 문장으로 나누면 탐구 2표·실험평가 1표가 됩니다. 같은 수행 내용이라도 문장 분할에 따라 답이 바뀌므로, 표의 행·문장·하위 요소 중 무엇을 투표 단위로 삼는지 고정해야 합니다.

**4. 개선 제안 — 차단 아님**

1. 사례마다 사례 ID와 적용 규칙 번호를 붙이면 문서·JSON 대조가 쉬워집니다.
2. 포함·제외가 **주활동 기준**인지 명시하면, 제외 사례에 해당 활동이 보조로 남는 이유가 명확해집니다.
3. 모든 활동에 공통인 근거 유형은 공통 정의를 참조한다고 표시하고, JSON의 공통 `evidence_types`와 연결하면 좋겠습니다.
