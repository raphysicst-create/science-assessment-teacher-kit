두 라벨러(Claude fable, astra ultra)가 5개교 원문에서 따로 단 라벨은 **항목 42 = 42, 짝 42/42**로 항목 수가 완전히 같았다. 필드 불일치 122건은 규칙 0~6(2026-11-08 사용자 결정)과 아래 "부서장이 정한 것"으로 전부 풀렸다. 사람 판정은 **활동 라벨 2건**뿐이다. 둘 다 정의 v2의 빈칸(집계 단위)이라 답이 정의 v3의 규칙이 된다. 번호와 답만 보내면 된다(예: A1 1, A2 1).

## A. 사람 판정 (2문항, 추천안 1번)

### A1. 평문 방법 문장을 투표 단위로 세는가 — 김해모산중 2학년 1학기 「탐구보고서」
- 원문: 요약표 방법 칸 "빛과 파동 탐구 수행 및 보고서 작성하기", 세부표 "빛의 반사와 굴절에 관한 탐구 수행 및 보고서 작성". 체크란 없음. 평가요소 "빛의 반사 / 빛의 굴절 / 거울과 렌즈"(활동 낱말 없음). 채점표 없음.
- Claude: **작성**(보고서 = 형식 표지 → 기본 작성, '탐구 수행'은 표지 분류표에 없어 0표, 전부 0표라 기본 유지). astra: **탐구**(평문 방법 문장도 E층 1단위로 세어 '탐구 수행' 탐구 1표, 작성은 보조).
- 1번(추천): **탐구**. 정의 v2 R4는 "제목·평가영역은 항상 투표"인데 체크란이 없는 학교는 방법 평문이 사실상 과제 설명이다. 평문 방법 문장을 E층 1단위로 센다고 정의에 적는다(v3). 화면: 이 항목이 "탐구" 탭에 나온다. 보고서만 있는 양식의 학교(요약표형)에서 기권·작성 쏠림이 줄어든다.
- 2번: 작성. 평문 방법은 표지 분류만 한다. 화면: "작성" 탭. 체크란 없는 학교의 과제는 대부분 작성·기권으로 간다.

### A2. R5③ 동률일 때 표 0인 기본 활동이 주가 되는가 — 치평중 1학년 1학기 「생물의 분류 만들기」
- 원문: 체크 ☑실험·실습(글꼴 기호 gfedcb). 평가요소 "생물분류체계(5계)의 특징을 바르게 설명하기 / 생물 카드를 계 수준으로 올바르게 분류하기". 채점기준 ①~⑤: 설명·분류·순서도·참여.
- Claude: **실험평가**(제목 '만들기' 제작 2, 분류 분석 2로 최다 동률 → R5③대로 기본 D 유지. 실험 수행 요소는 없음). astra: **분석**(제목의 '분류'를 분석 1표로 더 세어 분석 3 > 제작 2).
- 1번(추천): **분석**. 동률이어도 기본 활동이 0표이면 기본을 지키지 않고 동률 후보 중 S층(채점기준) 표가 많은 쪽을 주로 한다(여기서는 분석 S 4 > 제작 S 0). 정의 v3 R5③에 "D가 0표이고 동률이면 S층으로 가른다"를 더한다. 화면: "분석" 탭에 나온다. 체크값이 양식 기본값(실험·실습)인 학교에서 실험평가 오분류가 줄어든다.
- 2번: 실험평가(규칙 그대로). 화면: "실험평가" 탭. 실험 요소가 없는 과제가 실험평가에 섞인다.
