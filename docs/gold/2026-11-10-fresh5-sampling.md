# S20 품질 확인용 새 학교 표본 추출 기록 (2026-11-10, fresh5)

- 목적: S20(AI 우선 과제 추출) 뒤 공개판의 품질(재현율·정밀도·방법·활동)을 처음 보는 학교로 한 번 잰다(브리프 완료 기준 3). 이 숫자를 보고 규칙·지시문을 고치지 않는다(맹검 보호).
- 방법: `docs/gold/2026-11-10-fresh4-sampling.md`와 같은 규칙, 같은 스크립트 `scripts/sample_gold2_schools.py`(결정적)에 **새 시드**와 시도 수 3을 준다. 아래는 **추첨 전**에 고정했다(이 문서 작성 뒤에 추첨).
  - 1단계 seed **2026112005**, 시도 3곳(`--count 3`): 층 목록(시·구 3·군 2)을 같은 난수로 섞은 앞 3개를 쓴다. 군 없는 시도에 군이 오면 시·구로 바꾼다. 3곳 중 1곳(시·구 층일 때만)은 사립만.
  - 앞 표본에서 뺄 명단: 개발 12·보충 20·정답 10·스모크·dev(스크립트 기본) + **gold2 5**(`--exclude-roster middle-gold2-5.csv`) + **fresh3 3**(`middle-fresh3.csv`) + **fresh4 3**(`middle-fresh4.csv`). 그 명단의 시군구는 1단계 표본틀에서, 학교는 2단계에서 뺀다.
  - 2단계 seed **2026112006**: 학교알리미 `search_school`(시도·시군구·중학교) 목록을 `data/rosters/fresh5-frames.json`에 저장, 제외 규칙 적용, 이름순 정렬 후 섞어 첫 학교 선정.
  - 제외·대체 규칙은 gold2·fresh3·fresh4 문서와 같다(특성화·분교·개교 전 제외, 코드 미확인·중1·2 과학 평가계획 없음·수집 실패면 다음 순서). 내용이 마음에 들지 않는다는 이유로 바꾸지 않는다.
- 명단 `data/rosters/middle-fresh5.csv`, 학교 ID `ms-fresh5-<시도>-<city|gun>`, 회차 키 `2026-round-3-fresh5`(2학기 공시)·`2026-round-1-fresh5`(1학기 공시).
- 수집은 학교알리미 수집 간격 기본값 그대로 한다. 수집·변환·AI 호출 시간을 학교 단위로 재서 전국판 실행 계획(완료 기준 4)에 쓴다.
- 라벨 세트는 만들지 않는다. 확인은 astra 한 번: 원문을 먼저 읽고 과제를 적은 뒤 공개 카드 전수를 판정한다(S18·S19와 같은 방식). 파이프라인을 다 돌린 뒤에 한다. 판정 전에 공개 카드 id 목록과 DB 해시를 고정한다. 숫자는 `scripts/count_astra_card_verdicts.py`로 합산한다.
- 통계 한계: 3개교·약 20~50과제. 오류 0이어도 95% 상한 약 3/n(n=30이면 10%). 합격선 판정이 아니라 공개 결정용 참고 숫자다.
