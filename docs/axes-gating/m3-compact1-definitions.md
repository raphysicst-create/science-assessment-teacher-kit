## 2. 활동 축 판정 규칙

활동 = 학생이 점수를 받기 위해 주로 하는 행위. 평가 방법 칸의 체크값이 첫 근거이고, 체크가 여럿이거나 체크와 채점 요소가 어긋나면 평가요소·채점기준 투표가 정한다. 제목·평가영역 칸도 한 단위씩 투표한다(제목 단독으로 체크를 덮거나 동률을 깨지 못한다). 평가 주체·편성 표지(교사 관찰 및 기록·교사평가·관찰 평가·자기평가·동료평가·개별/모둠)는 활동 근거가 아니다. 보고서 계열은 형식 표지라 요소가 주활동을 정하고 작성은 보조로 남는다.

- R1 체크값: 체크된 선택지(기타는 괄호 내용, 괄호가 비면 후보 없음, 괄호 내용이 두 표지에 걸리면 머리명사 기준)를 아래 표지 표로 바꾼다. scorer_marker('과정중심평가' 포함)는 근거가 아니다. 요약표·세부표·진도표의 방법 표기가 서로 다르면 그 수행평가의 방법 칸(체크·평문)을 따른다.
- R2 후보 집합 C = 체크 표지의 기본 활동. 보고서 계열은 C에 작성을 넣되 형식 표지로 본다.
- R3 체크값이 없으면 평문 방법을 같은 표로 바꿔 C를 만든다. 그것도 없으면 제목·평가영역의 내용어가 단원·개념명과 방법어(실험, 프로젝트, 포트폴리오, 보고서, 글쓰기, 논술, 서·논술형, 발표, 구술, 토론, 탐구, 탐구활동)뿐일 때 그 방법어의 기본 활동을 C에 넣는다('…관계 실험'·'실험 활동 평가'→실험평가, '자유 탐구'→탐구, '과학 글쓰기'→작성).
- R4 투표 단위. E층 = 제목 1단위 · 평가영역 칸 1단위 · 평가요소 칸과 과제 설명 칸(글머리·번호·가운뎃점·'및' 나열은 항목마다 1단위로 펼친다: '실험 계획·수행 및 안전 준수' → 실험 계획 / 실험 수행 / 안전 준수). S층 = 채점기준 표의 요소마다 최고 수준 문장 하나(수준 반복은 세지 않는다). 세지 않는 것: 성취기준별 성취수준 표, 진도표·수업 세부 방법 칸, 학생 유의사항. 단위마다 활동 사전과 대조해 맞는 활동마다 최대 1표(공백을 지우고 어간으로 대조: 구분하/구분할/구분함 = 구분, 안전수칙 = 안전 수칙). 사전 제외 문구가 든 단위에는 그 활동 표를 주지 않는다. 제작 동사(만들기·제작·디자인)로 끝나는 제목은 제작 2표, 목적어가 노트·포트폴리오·보고서·계획서·글·일기·일지·시나리오·발표 자료면 제작 0표.
- R5 C가 1개(D): E층 표로 정한다. 기본은 D. 이 순서로 전환한다. ① D가 추론·설명이고 E층 작성 ≥1 → 작성. ② D가 탐구(프로젝트)이고 E층 제작 ≥1 → 제작. ③ X≠D의 E층 표 ≥2이고 X 표 > D 표 → X(여럿이면 최다, 최다가 동률이면 D 유지). ④ D가 보고서 계열이면 E층 최다가 주. 최다 동률이면 제목이 표를 준 쪽, 그래도 못 가르면 동률에 탐구가 있으면 탐구, 없으면 작성. E층 표가 전부 0이면 S층으로 같은 절차를 한 번 더. 전환되면 D는 보조.
- R6 C가 2개 이상: E층 표(10개 활동 전부) 최다가 주. 최다가 동률이면 그중 C에 든 것이 하나뿐일 때 그것, 아니면 기권('근거 동률'). E층이 전부 0이면 S층으로 한 번 더, 그래도 0이면 기권('체크 여러 개·요소 근거 없음'). C의 기본 활동은 모두 보조.
- R7 C가 비었으면 E층 최다, 없으면 S층 최다(동률 → 기권 '근거 동률'). 둘 다 0이면 기권('근거 없음').
- R8 보조활동: 주활동을 뺀 C의 기본 활동과, E층·S층 합쳐 표 ≥1인 활동.
- R9 특례: IB식 탐구 평가기준('탐구 및 설계', '처리와 평가', 가설·변수·데이터 해석·결론·개선 방안 기술어)으로 채점하면 탐구가 주. 요소가 역량 이름뿐(창의성·전달력·소통·반응 공유)이고 구술·발표가 체크됐으면 발표·토론.

기권 사유: 근거 없음 / 근거 동률 / 체크 여러 개·요소 근거 없음 / 체크 판독 불가

## 3. 활동 10개 정의

활동마다 정의, 기본 체크값, 요소 사전(투표 낱말), 경계 판정 방향. 경계는 **주활동 기준**이다(밀려난 활동은 보조로 남을 수 있다).

### 3.1 탐구 (`inquiry`)

**정의.** 탐구 문제 설정·가설·변인 통제·탐구 설계·수행·결론 도출로 이어지는 탐구 과정(또는 그 계획서)을 학생이 해냈는지가 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 프로젝트
- 요소 사전: 탐구 문제, 탐구 주제, 가설, 변인, 탐구 설계, 실험 설계, 실험 계획, 탐구 계획, 탐구계획, 결론 도출, 결론을 도출, 결론을 요약, 탐구 과정, 탐구과정, 자유탐구, 자유 탐구, 탐구 방법, 탐구 수행, 탐구수행, 탐구를 설계, 탐구 및 설계, 처리와 평가, 검증 가능한 가설, 변수 조작, 데이터 수집, 가설의 타당성
- 경계:
  - 체크가 평가 주체 표지뿐이면 요소로 판정한다(요소가 가설 설정·탐구 설계 → 탐구).
  - 단일 체크(예: 서·논술)의 기본 활동과 다른 탐구가 E층 2표 이상이고 기본 활동 표보다 많으면 탐구 주, 기본 활동 보조.
  - 보고서·프로젝트 체크에서 요소가 탐구 주제·탐구 계획·변인 통제면 탐구 주, 작성 보조.
  - 제목에 '탐구'가 있어도 체크와 요소(이해·설명·모식도)가 추론·설명이면 추론·설명. 제목은 체크를 덮지 않는다.
  - 영역명이 '탐구 보고서'여도 평문 방법이 '서술형'이면 평문 방법이 먼저 → 추론·설명.
  - 제목 '탐구하기'에 실험·실습 체크이고 요소에서 2표 이상 앞선 활동이 없으면 실험평가 주, 탐구·분석 보조.
  - 프로젝트 체크에서 요소 칸이 역량 이름(제외 문구)뿐이라 E층 0이면 S층으로 본다. S층 실험평가 1·분석 1은 전환 문턱(2표, 기본보다 많음) 미만이라 탐구 유지.

### 3.2 실험평가 (`experiment`)

**정의.** 실험 기구를 다루고 실험·관찰을 실제로 수행하는 과정(절차 준수·기구 조작·안전·참여)이 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 실험·실습, 실험 평가, 실험, 실기·시연
- 요소 사전: 실험 수행, 실험을 수행, 실험을 진행, 실험 기구, 기구 조작, 기구를 바르게, 기구 사용, 도구 사용, 실험 도구, 실험 과정, 실험 절차, 실험 안전, 안전 수칙을 준수, 안전 수칙 준수, 안전 준수, 안전에 유의, 안전 규칙을 준수, 실험실 안전에, 실험실 안전 수칙, 안전 사항, 실험 참여, 실험에 참여, 정리 정돈, 정리정돈, 현미경, 관찰하기, 관찰함, 실험하기, 실험 방법, 실험 준비
- 사전 제외 문구(이 말이 든 문장에는 표를 주지 않음): 안전수칙을작성, 안전수칙작성, 안전수칙을서술, 안전수칙서술, 안전수칙을설명
- 경계:
  - 실험·실습 체크, 요소 실험 수행·결과 분석 → 실험평가 주, 분석 보조.
  - 제목이 '측정하기'여도 실험·실습 체크 하나이고 요소 투표에서 다른 활동들이 동률이면 전환 없이 실험평가 유지.
  - 실험 결과를 쓰더라도 서·논술 체크이고 실험 수행을 채점하지 않으면 추론·설명.
  - 자료 제시형(실험 수행 없음)에서 요소가 그래프·구간 구분이면 분석.
  - 실험·실습 체크여도 요소가 측정값·계산 결과(계산·측정 2표 이상, 실험평가 표보다 많음)면 계산·측정 주, 실험평가 보조.
  - 측정이 실험 수행의 일부이고 계산·측정 표가 2 미만이면 실험평가 주, 계산·측정 보조.
  - 제목이 '실험·실습'이어도 E층 탐구 표(실험 설계·결론 도출·탐구 주제, 3)가 2 이상이고 실험평가 표(2)보다 많으면 탐구 주, 실험평가 보조.
  - 탐구 표가 실험평가 표와 같으면(2:2) 전환 없이 실험평가 유지, 탐구·분석 보조.

### 3.3 작성 (`writing`)

**정의.** 글·서평·일기·시나리오·기사처럼 글 형식의 산출물을 쓰는 것이 과제이고, 제목·영역명이 그 글 형식을 지정하거나 글의 구성·흐름·문장 같은 글 자체의 질이 채점 요소에 들어 있는 활동이다.

- 기본으로 가리키는 체크값: 보고서, 탐구보고서, 조사·관찰 보고서, 보고서 평가
- 요소 사전: 글쓰기, 글 쓰기, 서평, 일기, 시나리오, 서론, 본론, 도입-전개-정리, 글의 구조, 글의 흐름, 문장이, 문법, 논설문, 기사, 편지, 수필, 에세이, 양식에 부합, 일지
- 경계:
  - 서·논술 체크여도 요소가 글의 구조·문장·문법·글의 흐름·양식이면 작성 주, 추론·설명 보조(서평·시나리오).
  - '서술하기'는 글 형식 표지가 아니다 → 추론·설명.
  - 논술(설명 글)이고 글 구조 채점 요소가 없으면 추론·설명.
  - '보고서 작성' 제목이어도 요소가 탐구 과정이면 탐구 주, 작성 보조.
  - '일기 쓰기'처럼 형식만 정하고 채점 요소 최다가 분류면 분석 주, 작성 보조.
  - 보고서 계열 체크만 있고 요소가 측정이면 계산·측정 주, 작성 보조.
  - 평가영역 칸 '과학 글쓰기'도 작성 1표다. 서·논술 체크(D=추론·설명)에서 작성 표 ≥1이면 R5①로 작성 주. 작성 전환은 다른 전환보다 먼저 본다.

### 3.4 제작 (`making`)

**정의.** 모형·장치·악기·포스터·카드뉴스·달력·지도·만화 같은 물리적·시각적 산출물을 만드는 것이 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 없음(요소·제목 투표로만 주활동이 된다)
- 요소 사전: 만들기, 만들어, 만들 수, 제작, 디자인, 포스터, 카드뉴스, 카드 뉴스, 달력, 지도 만들기, 지도 제작, 지도만들기, 작품, 만화, 모형을 제작, 모형 제작, 재창작, 전람회, 부스, 산출물, 타이포그래피, 악기, 장치를 만들, 장치 제작, 장치를 제작
- 사전 제외 문구(이 말이 든 문장에는 표를 주지 않음): 발표자료, 보고서, 계획서, 학습지, 노트, 포트폴리오, 일기, 일지, 시나리오, 전원장치, 실험장치, 장치를조작, 지도에
- 제목 동사 가중: 제작 동사(만들기·제작·디자인)로 끝나는 제목은 2표. 목적어가 노트·포트폴리오·보고서·계획서·글·일기·시나리오면 0표
- 경계:
  - 체크가 둘(프로젝트+실험·실습)이고 요소 '만들기' 1표가 유일한 투표면 제작 주, 체크 기본 활동 보조.
  - 평문 '프로젝트 평가'(기본 탐구)에서 산출물(포스터·달력) 표가 1표라도 있으면 제작 주, 탐구 보조(R5②, 1표 문턱).
  - 체크 여럿에서 제목 '만들기' 2표를 포함한 제작 표가 최다면 제작 주.
  - 모식도·그래프 그리기, 층 구조를 그려 '표현'하는 것은 설명 수단이지 제작이 아니다 → 추론·설명. 그래프 작성은 분석 표다.
  - '과학노트 만들기'처럼 목적어가 노트·포트폴리오·보고서·글이면 제작 표가 없다.
  - 제목 '만들기' 제작 2표와 요소 추론·설명 2표가 동률이고 체크가 둘(서술·논술, 실기·시연)이면 R6: 동률 중 C에 든 추론·설명이 주, 제작 보조. 제목은 동률을 깨지 못한다.

### 3.5 분석 (`analysis`)

**정의.** 주어진 자료·그래프·관찰 결과를 해석·분류·비교해 규칙성이나 관계를 찾아내는 것이 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 없음(요소·제목 투표로만 주활동이 된다)
- 요소 사전: 분석, 해석, 분류, 비교, 그래프, 자료 해석, 자료 분석, 자료를 근거, 자료에서, 자료 변환, 데이터 분석, 데이터를 해석, 규칙성, 관계 도출, 관계를 도출, 구분, 구별, 순서도, 경향, 결과 해석, 표로 정리, 분포 차이
- 경계:
  - 보고서 체크는 형식 표지라 요소 투표(그래프 분석·구분 2 > 계산·측정 1)로 분석 주.
  - 서·논술 체크에서 분류 2표 > 서술 1표, 또는 그래프 작성·구간 구분 2표 > 설명 1표면 분석 주.
  - 체크가 둘 이상이면 E층 최다가 주(분류 표 최다 → 분석).
  - 제목이 '해석하기'·'분석'이어도 요소가 '설명' 위주면 추론·설명 주, 분석 보조. 제목은 체크·요소를 덮지 않는다.
  - '추리·추론'은 주어진 자료 해석이 아니라 설명의 일부 → 추론·설명.
  - 분석 표(2)가 기본 활동 추론·설명 표(2)보다 많지 않으면 전환 없음, 분석 보조.

### 3.6 추론·설명 (`explanation`)

**정의.** 과학 개념·원리·현상을 글·식·모형으로 설명·서술·추론·예측하는 것(서·논술형 문항 풀이 포함)이 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 서·논술, 서술·논술, 서술형, 논술형, 논술, 서술, 서·논술형, 서논술형
- 요소 사전: 설명, 서술, 추론, 추리, 논술, 원리, 이유, 까닭, 개념, 예측, 입자 모형으로, 모형으로 표현, 모식도, 서·논술형 문제, 서논술형 문항, 문항, 정의를, 설명하기, 비유
- 경계:
  - 서·논술형 체크 하나에 요소가 서술이면 추론·설명. 영역명 '과학 논술'·논술형 체크도 추론·설명.
  - '서·논술형 문제 해결하기'는 문항 풀이라 추론·설명 표다(포트폴리오 체크는 보조).
  - 요소가 글 형식(글의 구조·문장)이면 작성, 요소 최다가 분류면 분석.
  - 서·논술 체크여도 요소가 탐구 계획서·탐구 설계(탐구 2 > 추론·설명 1)면 탐구 주.
  - 제목 '제안하기'·요소 '실천 방법 제안'·그 최고 수준 문장이 문제해결 3표이고 추론·설명 2표보다 많으면 R5③으로 문제해결 주.
  - 포트폴리오 체크여도 요소가 전부 개념 설명·논술이고 과정평가 표가 0이면 추론·설명 주, 과정평가 보조.

### 3.7 발표·토론 (`presentation`)

**정의.** 학생이 말로 발표하거나 토의·토론에 참여하는 수행(내용 전달·표현·청중 소통·토론 참여)이 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 구술·발표, 토의·토론, 토론·토의, 발표, 구술
- 요소 사전: 발표, 토론, 토의, 청중, 구술, 질문에 논리적으로 답변, 말할 수, 페임랩, 표현력, 시선, 전달력, 소통 능력, 소통, 반응 공유, 시연
- 경계:
  - 구술·발표 체크에 요소가 의사소통·표현력·청중이면 발표·토론.
  - 평문 방법 '구술·발표'만 있고 요소가 없으면 평문 기본 활동(발표·토론).
  - 방법·요소가 모두 없고 제목 동사 '발표하기'만 있으면 발표·토론.
  - 서·논술+구술·발표 체크에서 요소가 분류 3표면 분석 주, 발표·토론·추론·설명 보조.
  - 체크 여럿에 요소가 없어 투표 0이면 기권, 체크 기본 활동은 모두 보조.
  - 발표 요소가 있어도 최다 투표 활동(예: 제작)이 주, 발표·토론 보조.
  - 투표 동률(작성 1·발표·토론 1·추론·설명 1)에서 동률 중 체크 기본 활동이 둘 이상이면 기권, 모두 보조.

### 3.8 계산·측정 (`measurement`)

**정의.** 측정값을 얻고 계산해 밀도·탄성력·부력·속력 같은 수치 결과를 내는 것(측정 정확도·계산 과정·단위)이 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 없음(요소·제목 투표로만 주활동이 된다)
- 요소 사전: 측정, 계산, 를 구하기, 을 구하기, 를 구할, 을 구할, 를 구함, 을 구함, 밀도 구하, 거리 구하, 속력 구하, 밀도, 단위, 측정값, 눈금, 저울, 센서, 수치, 풀이 과정, 값을
- 경계:
  - 실험·실습 체크에 요소 부피 측정·질량 측정·밀도 구하기(계산·측정 3표)면 계산·측정 주, 실험평가 보조.
  - 체크 여럿에서 요소 측정·계산(밀도·부력 구하기)이 최다면 계산·측정 주.
  - 측정이 실험 수행의 일부이고 계산 결과를 채점하지 않으면 실험평가 주, 계산·측정 보조.
  - 제목 '측정하기'여도 요소가 안전·자료 해석·개념 설명이면 실험평가 유지.
  - 제목도 투표 단위다. '부력 측정 실험' 제목 1표 + 요소 측정 1표 = 계산·측정 2 : 추론·설명 1, 체크 둘 → R6로 계산·측정 주, 체크 기본 활동 둘은 보조.
  - 보고서 계열 체크만 있고 요소 '측정' 1표가 유일하면 계산·측정 주, 작성 보조.

### 3.9 과정평가 (`process`)

**정의.** 한 과제의 결과물이 아니라 수업 과정 전반의 학습지·노트·포트폴리오 누적, 참여·태도·기록의 성실성을 채점하는 활동이다.

- 기본으로 가리키는 체크값: 포트폴리오, 과학 노트, 과학노트, 학습지
- 요소 사전: 학습지, 활동지, 참여, 태도, 성실, 포트폴리오, 과제수행, 과제 수행, 모둠활동, 제출, 누락, 빠짐없이, 성찰, 느낀점, 정리가, 정리함, 이행, 과정 기록, 과정기록, 노트
- 경계:
  - 서술형+기타 체크여도 제목(학습지 정리·과제수행·모둠활동)과 요소(포트폴리오 이행)가 과정평가 2표면 과정평가 주, 추론·설명 보조.
  - 평문 '포트폴리오'에 요소 학습지 작성·과정 기록·성찰, 또는 활동 과제 제출·수업 참여도면 과정평가.
  - 포트폴리오 체크여도 요소가 전부 개념 설명·논술이거나 서·논술형 문제 해결(문항 풀이)이면 추론·설명 주, 과정평가 보조.
  - '구성·목차·가독성'은 어느 사전에도 없어 표가 없다. 요소 '충실성'(과정평가 1)만 있으면 기본 활동 유지, 보조 없음.
  - 체크 여럿이면 E층 최다(과정평가 2: 활동지·정리)가 주, 나머지 체크 기본 활동과 1표 활동은 보조.
  - '과학노트 만들기'(포트폴리오+보고서 계열 체크): 요소 개념 설명·원리 이해(추론·설명 7)가 활동지 기록·성찰(과정평가 4)보다 많아 R6로 추론·설명 주, 과정평가 보조. 이름보다 요소가 결정한다.
  - '교사 관찰 및 기록'·'교사평가'·'자기평가'·'동료평가'·'개별수행'·'모둠' 같은 평가 주체·편성 표지는 활동 근거가 아니다. 요소로 판정한다.

### 3.10 문제해결 (`problem_solving`)

**정의.** 실생활·주어진 문제 상황에 대해 과학 지식을 적용해 해결 방안·대안·실천 방법을 고안하고 제안하는 것이 채점의 중심인 활동이다.

- 기본으로 가리키는 체크값: 문제해결, 문제 해결
- 요소 사전: 해결 방안, 해결방안, 방안을 제시, 방안 제시, 방안을, 대안, 제안, 실천 방법, 실천 방안, 실천하, 해결책, 개선, 절약, 효율 높이는 방법, 해결하기 위한, 문제 상황
- 사전 제외 문구(이 말이 든 문장에는 표를 주지 않음): 서·논술형 문제, 서논술형 문제, 문항, 문제 해결 능력, 문제해결력, 문제 해결력, 문제 해결 정도
- 경계:
  - 서·논술 체크에서 제목 '제안하기' 1표 + 요소 실천 방법 제안 1표 = 문제해결 2표 > 추론·설명 1표면 문제해결 주.
  - 방법·체크가 없고 요소 '에너지 효율 높이는 방법'이 2표로 최다면 문제해결 주, 제작 보조.
  - '서·논술형 문제 해결', '문제를 모두 해결함'(문항 정답 표현)은 문항 풀이 → 추론·설명. 문제해결 표를 주지 않는다.
  - 투표 동률(문제해결 1·분석 1·추론·설명 1)에서 동률 중 체크 기본 활동이 추론·설명 하나뿐이면 추론·설명 주, 나머지 보조.
  - 체크 '기타(문제해결)'은 후보를 만들 뿐 표가 아니다. 역량 이름('문제해결력')은 제외 문구. E층 표가 '이해'(추론·설명 1)뿐이면 R6로 추론·설명 주, 문제해결은 보조.
  - 작성 전환(글 형식 표지 1표)이 문제해결 전환보다 먼저 적용된다.
