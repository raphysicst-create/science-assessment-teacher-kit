# "과제 하나" 정의 제안서 (E1, 2026-11-10)

**고를 것:** 학교가 점수·비율 없이 *과제 칸 하나*에 활동 문장을 여러 줄 적었을 때, 카드를 몇 장 만들까?
**추천: C안.** 같은 행에 과제명이 따로 없으면 줄마다 과제로 나누고, 과제명이 따로 있으면 줄은 그 과제의 내용으로 둡니다.

## 1. 실제 원문 (공산중 1학년 2학기, fresh4 변환본 461~465줄)

| 평가 방법 | 수행 과제 칸 | 시기 |
|---|---|---|
| 자기성찰·학습과정·동료·보고서평가 | 자기주도학습 과정 성찰 포트폴리오 제작 / 보일 법칙 실험 및 보고서 작성하기 / 샤를 법칙 실험 및 보고서 작성하기 / 생활 속 … 현상 조사 및 발표하기 | 9월~10월 |
| 과학프로젝트평가 · **힘의 특징을 이용한 기구 설계 및 발표하기** | - 여러 가지 힘 나타내기 / - 우리 주변의 기구나 장치의 힘의 원리 찾기 / … | 9월 1~2주 |

- 윗줄(461~463줄, 3칸): 과제명이 따로 없고, 칸 안의 줄 하나하나가 과제 문장입니다. 같은 문서 510줄 진도표에도 "[수행과제] 보일 법칙 실험 및 보고서 작성하기"로 따로 나옵니다.
- 아랫줄(464~465줄, 2칸): 과제명이 따로 있고, 칸 안의 줄은 그 과제의 단계입니다.
- 지금 공개판: 윗줄 3칸은 4~5줄을 이어 붙인 제목의 카드 3장입니다. 아랫줄 2칸은 단계 목록이 제목이 된 카드 2장입니다. 제목을 고르는 문제는 따로 있고 백로그에 적었습니다.

## 3. 정의안 셋

| | A. 칸 하나 = 과제 하나 (지금) | B. 줄마다 과제 | **C. 과제명 없는 칸만 줄마다 (추천)** |
|---|---|---|---|
| 규칙 | 따로 만점·비율이 없으면 줄이 몇 개든 칸 하나가 과제 하나 | 칸 안의 줄 하나가 과제 하나 | 같은 행에 과제명이 따로 없으면 줄마다 과제. 과제명이 있으면 줄은 내용 |
| 교사에게 좋은 점 | 학교가 묶은 단위를 그대로 보여 줌. 점수 단위와 같음 | 활동 하나하나를 검색해 찾음 | 카드 한 장 = 활동 하나. 단계 목록은 과제 안에 남음 |
| 교사에게 나쁜 점 | 카드 제목이 활동 4~5개를 이어 붙인 글이라 무엇을 하는 과제인지 안 보임. 활동 축도 정하지 못함 | "여러 가지 힘 나타내기" 같은 단계 하나가 카드가 됨(가짜 과제) | 나뉜 카드에는 각자의 만점·채점 기준이 없음(학교가 안 줬음). 시기·방법은 같은 칸 값을 함께 씀 |
| 개발 사례 카드 (5칸) | 5장 | 18장 | 13장 |
| 개발 재현율 (그 안의 키 기준) | 62/69 = 0.899 (키를 줄여야 하고 기준 0.90 아래) | 75/82 = 0.915 (단계 7줄이 키에 들어감) | **70/77 = 0.909** (지금 키 그대로) |
| 묶음 1 공개판 (685장) | 변화 0 | 해당 2칸이 과제 6개로 (+4, 단계 줄이 과제가 됨) | 변화 0 |
| 정답 키와 일관성 | astra 키(줄마다)와 어긋나 키를 고쳐야 함 | 키의 T12·T13을 단계로 쪼개야 함 | **astra 키 T01~T13과 그대로 맞음** |

- 재현율은 "그 안이 구현되면 만들어진 과제마다 맞는 카드가 하나씩 생긴다"고 보고 센 값입니다(`cases-summary.json` → `options`).
- 참고: 지금 합친 카드 3장을 막기만 하면 59/77입니다(N2 계산). 그 길은 위 세 안에 들어 있지 않습니다.

## 4. 추천 C의 이유
1. 교사가 받는 카드 한 장이 과제 하나가 됩니다(정밀도). A는 합친 카드를 그대로 두고, B는 단계 줄을 가짜 과제로 만듭니다.
2. 이미 있는 독립 키(astra, T01~T13)가 C와 같은 기준이라 키를 고치지 않아도 됩니다. 재현율도 기준 0.90 위에 남습니다.
3. 판정이 "같은 행에 과제명 칸이 따로 있는가"라는 표 구조로 정해집니다. 코드(`count_listed_cells.py`의 `classify`)로 재검산할 수 있습니다.
4. 묶음 1 공개판은 바뀌지 않습니다. 전국판에서 공산중 같은 학교가 나오면 그때만 나뉩니다.

## 5. 확정되면 AI 지시문에 넣을 문장 (C)
지금 `scripts/prompts/middle_ai_first_v1.md` 14~16줄("한 영역 안에 활동이 여러 개 … 그 영역이 과제 하나다", 자유학기 문장)을 아래로 바꿉니다.
> - 과제명 칸(수행 과제·과제명 등) 한 칸에 완결된 활동 문장이 여러 줄 있고, 줄마다 따로 만점·비율이 없고, 같은 행에 그 줄들을 묶는 과제명 칸이 따로 없으면 줄마다 과제 하나로 적는다.
> - 같은 행에 과제명이나 영역명(예: '액체의 비열탐구')이 따로 있으면 옆 칸의 줄(- • ▪ 표시 단계, 평가 내용)은 그 과제의 내용이다. 과제 하나로 적는다.
> - 여러 칸에 똑같이 들어간 줄(예: '자기주도학습 과정 성찰 포트폴리오 제작')은 과제 하나로 적는다.
> - 평가 방법 칸의 줄, 진도표의 수업 활동 줄, 칸 폭 때문에 두 줄로 꺾인 제목 하나는 나누지 않는다.
