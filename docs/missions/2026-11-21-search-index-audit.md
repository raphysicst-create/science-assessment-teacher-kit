- 확장 검사(스크래치 `ext_check.py`, DB 행으로 Python에서 기대값 계산): 2,675개 요청. 전체 페이지 1,083개(필터 없음, 학년, 성취기준 88 단독·단원 함께·학년 함께, 시도 18, 시도×학년, 시도×시군구 전부, 단원×시도), 첫 페이지·집계 수 1,592개. 집합·순서·건수·집계 수(단원·활동·학년·성취기준·시도·시군구, 정렬 포함) 어긋남 0. 일부러 값을 바꾸면 잡히는 것을 확인했다.
- 색인(인덱스): 필터의 EXISTS는 `idx_axes_axis_value`, 카드 축 조회는 기본키를 쓴다. 요청 하나 로컬 0.8~1.7초(집계 질의 6개가 대부분). 고칠 것 아님, 기록만.

문제
1. 라이브러리(`/cases`)에 공개 카드가 0장인 사례 **332건**이 나오고, 누르면 404("원문 상세를 찾을 수 없습니다"). 처음 것은 목록 46번째(2쪽). 원인: 감사 차단(`exclusions`)·정정(`corrections`)이 항목만 review로 바꾸고 `cases.title_basis`를 그대로 둔다. 목록·필터 수는 이 값을 믿는다. 11-10 판에도 20/153건 있던 문제.
2. 라이브러리 카드의 과제명 목록에 보류한 제목이 남은 사례 **2,016건**(대표 제목이 보류 제목인 사례 782건, 예: "정기시험 계획"). 같은 원인(`task_names_json`·`primary_task_name` 안 고침). 글 검색도 이 칸을 찾는다.
3. 시도 "전남광주통합특별시"(1,293사례)가 웹 URL 검증 목록(`reference-filters.ts` REGION_NAMES)에 없다. 화면에서 고르면 되지만 새로고침·링크 공유 때 시도·시군구 필터가 풀린다. 같은 지역에 옛 이름 광주광역시 17·전라남도 16사례가 따로 남아 있다.
4. 검색엔진 색인
   - 루트 `layout.tsx`의 `alternates.canonical: "/"`를 모든 페이지가 물려받는다. 하위 페이지가 모두 홈의 중복으로 표시된다.
   - `robots.ts`는 `/sitemap.xml`을 가리키지만 sitemap이 없다(404). 테스트는 주소 문자열만 본다.
   - `NEXT_PUBLIC_SITE_URL`이 빌드 때 없으면 canonical·OG·sitemap 주소가 `http://localhost:3000`이 된다. 배포 안내(`2026-11-20-nationwide-publish-decision.md`)에 이 설정이 없다.
   - 참고: 검색·상세 화면은 모두 브라우저에서 API로 그린다(`"use client"`). 상세 1만여 쪽의 제목·설명이 같다. JS를 읽지 않는 검색엔진에는 본문이 없다.

## 회고
- ① 산출물 기준: 공개 여부를 항목에서 바꾸는 단계는 사례 단위 표시값(title_basis·과제명 목록)도 다시 계산해야 한다. 검사로는 "source_detail 사례마다 bounded 항목 ≥1, 과제명은 bounded 제목만"을 게이트에 넣는다.
- ② 일하는 방식: 공식 검색 검사는 단원·활동·학년만 본다. 성취기준·지역·집계 수는 이번에 처음 전수로 봤다(통과).
