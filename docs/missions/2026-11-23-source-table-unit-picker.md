## 브리프
사용자(2026-11-23, 운영 사이트 캡처 두 장과 함께):
1. 자동 배포 켜지 말 것.
2. 원문 표가 `| 칸 | 칸 |` 글자로 보인다. 표로 보이게.
3. 단원 선택을 학년→단원 드롭다운으로. 성취기준이 코드로만 나온다.
4. 제목 밑에 블로그 https://blog.naver.com/raphysicst.

## 원인과 수정
- 원문 표: 공개 카드 34,296장 중 25,371장(74%)이 `<table>` 없이 `|` 문단이다. 원문의 한 표에 여러 평가가 이어져 있고, 카드가 그중 자기 줄만 잘라 쓰면 빌더(`build_science_catalog_db.close_table_fragments`)가 반쪽 표 태그를 ` | `(칸 경계)와 줄바꿈으로 바꿨기 때문. 데이터 재빌드는 AI 카드 검사까지 다시 돌아야 해서, 웹 표시 단계에서 복원한다: `app/lib/pipe-row-tables.ts`가 `|` 문단 묶음을 표로 되살리고(칸 안 줄바꿈은 `<br>`, 칸이 줄어든 행은 위 행 머리 칸을 세로로 늘림, "평가 요소" 등 표제어 행은 새 구역), 그 뒤 기존 구획 분리가 그대로 돈다. 원문 글자는 바꾸지 않는다.
- 학년·단원: 칩 23개 → 학년·단원·성취기준 드롭다운. 단원은 1학년(01~07)·2학년(08~15)·3학년(16~23) 묶음. 운영 API에서 1학년 사례는 01~07, 2학년은 08~15에 몰려 있다(16~23은 학년마다 수십 건). 학년을 바꾸면 다른 학년 묶음 단원은 지운다.
- 성취기준 문구: `app/lib/science-standards.ts`에 87개. 출처 curriculum-kr-secondary MCP `summary`(공식 원문 끝만 "~하기"로 바꾼 mechanical-derivative, kr-nec-2024-3-annex9). PDF 줄바꿈 띄어쓰기("추 론하기")를 지웠다. 고르면 아래에 전문을 보여 준다.
- 블로그: 머리글 제목 아래 "블로그 · blog.naver.com/raphysicst"(새 탭).

## 확인
- 실제 `|` 카드 3,000장 무작위(seed 7): 2,958장(98.6%) 표로 복원. `|` 문단이 남은 카드 189장(대부분 표 한 줄짜리라 바꾸지 않음). 글자 빠짐 0(차이 28장은 기존 구획 분리가 머리 칸을 다시 보여 주는 것).
- 캡처의 단열 카드(`5ba04950…`): 성취기준·성취수준, 채점 기준·배점이 각각 표로, 성취기준 칸·채점 요소 칸이 세로 병합.
- 로컬(실데이터) 화면: 학년·단원·성취기준 드롭다운, 성취기준 문구, 1280px·휴대폰 폭 머리글 블로그 링크.
- `npm run lint:web`, `npm run build`, `npm run test`(Python 2,941·웹 90·제품 경계) 통과.

## 남은 것
- 운영 재배포(사람 결정): `npm run stage:vercel` 뒤 저장소 밖 복사본에서 `npx vercel deploy --prod`(배포 문서 11-23 줄).
- 근본 수정 백로그: 빌더가 반쪽 표를 글자로 펴지 말고 표 조각을 닫아 HTML로 남기기. 재빌드 때 AI 카드 검사가 다시 도는 비용 때문에 이번엔 웹에서 복원.

## 회고
- ① 산출물 기준: 원문 표시 화면 검사에 "표로 보이는 카드 비율"이 없어서 74%가 글자로 나가는 걸 놓쳤다. 표 복원율을 숫자로 본다.
